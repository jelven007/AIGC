# AI 使用与第三方来源记录

更新：2026-10-21。本文件提供核验原则，不将原作者宣传中的团队、特定 Coding 工具、素材生成过程或顶尖效果作为已证实记录。

## 1. 实际应用依赖

前端使用 React/Vite/TypeScript、Tailwind/Radix 等，业务使用 Supabase SDK/Auth/PostgreSQL/Storage/Edge Functions，MCP 使用 Python FastMCP/Starlette/HTTPX。版本和依赖以 [package.json](../package.json)、锁文件和 [requirements](requirements_mcp.txt) 为准；授权以各依赖许可证为准。

项目基于 Gitee 的原始代码继续迭代，保留 [LICENSE](../LICENSE) 与必要第三方版权说明。产品资料移除个人推广不等于删除软件许可证/原始版权。

## 2. 模型与输出

运行模型/Key/地址由管理员统一配置，13 槽表示协议目录而不是全部模型已开通。当前源码与供应商实测边界见 [AI 能力](../docs/ai/ai.md)。发布时记录供应商、模型/配置版本、输入素材使用权和真实生成样本，不记录 Key/JWT。

模型输出需人工确认商品事实、质量与使用条件；图片/视频不得用现成演示资源冒充真实任务成功。AI 辅助编写代码不替代测试证据，验证见 [报告](../docs/archive/reviews/TEST_REPORT_20261021.md)。

具体 AI Coding 工具/模型只有实际可核验使用记录时才披露；不编造工具归属、开发团队与履历。第三方示例与宣传地址不作为当前部署/验收证据。
