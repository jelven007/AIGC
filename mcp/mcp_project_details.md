# Shopro AI - 抖音/TikTok 电商 AIGC 带货视频系统 MCP 接入与项目说明

---

## 📖 使用说明

### 1. 输入 (Input)
* **商品描述与介绍**：可以直接输入原始商品卖点文字或在线商品详情页的 URL 链接（如淘宝、抖音、TikTok 链接）。
* **营销策略参数**：支持选择生成平台（如 TikTok、抖音、小红书、快手）、脚本目标语言（中文/英文/泰语/印尼语/越南语等）。
* **配音合成参数**：指定 StepAudio TTS 试听音色（如 `cixingnansheng` 等）、语速倍率（0.5x - 2.0x）和音量（0.1 - 1.0）。
* **视频渲染参数**：包括原始视频 Prompt、渲染比例（16:9、9:16）、画质分辨率（720p/1080p）以及选填的首帧参考图 URL。

### 2. 输出 (Output)
* **亮点提取数据**：自动分析出商品三大核心卖点、目标受众画像与关键痛点、首选营销切入点。
* **带货分镜脚本**：生成符合 AIDA 说服框架的高转化短视频脚本，包含具体的视觉分镜动作设计与匹配的数字人口播台词。
* **多语种脚本**：完美适配目标海外市场的纯外语脚本。
* **高质口播音频**：由 `stepaudio-2.5-tts` 合成的极具情感表达力的 MP3 音频二进制 Base64 编码数据。
* **高清带货视频**：由 `doubao-seedance-2-0-fast-260128` 异步渲染输出的 720p / 9:16 高清电商带货短视频 URL。

### 3. 使用步骤 (Usage Steps)
1. **服务拉起**：
   * 进入 `mcp` 文件夹，配置 `.env` 环境变量并执行 `python mcp_shopro_server.py`。服务在官网部署后，暴露外网可访问的 `https://f.playe.top/mcp` 端点。
2. **第一步：卖点分析**：
   * 调用 `extract_product_highlights` 工具，传入商品文案或链接，自动提取卖点。
3. **第二步：脚本生成**：
   * 调用 `generate_marketing_script` 工具，传入第一步解析出的卖点，以及目标受众和平台，生成多场景的营销带货脚本。
4. **第三步：小语种翻译**（如跨境带货）：
   * 调用 `translate_marketing_script` 工具，将中文脚本快速翻译为目标语言，且完美保留分镜括号与动作占位符。
5. **第四步：语音合成**：
   * 调用 `synthesize_voice_tts` 工具，把脚本台词转换为语音，生成 MP3 音频以备视频对齐。
6. **第五步：视频合成与轮询**：
   * 先调用 `enhance_prompt` 对分镜画面描述进行大模型增强，然后使用 `submit_video_generation` 提交给 Seedance 接口渲染。
   * 获取返回的 `request_id` 后，通过 `query_video_status` 轮询任务进度，直至生成状态为 `success` 并获取最终视频 URL。

### 4. 适用边界 (Boundaries)
* **网络依赖性**：商品 URL 卖点抓取依赖于链接的公开可访问性。对于需要高防机器人校验的电商网页，建议用户直接复制商品文案作为输入。
* **视频长度限制**：依托 Seedance 2.0 基础模型的渲染限制，单次图生视频/视频渲染时长通常在 5s 到 15s 之间，适合做爆款带货分镜素材的拼接与混剪，不适用于生成大段超长纪录片。
* **口播字数**：单段 TTS 语音合成最佳汉字长度在 200 字内，以保证最自然的人声呼吸节奏与口型对齐。

## 🛠️ 技术/工具路线

### 1. 核心 AI 大模型
* **文案与营销大模型**：**DeepSeek-V4-Pro** (`deepseek-ai/DeepSeek-V4-Pro`），承担商品卖点提取、AIDA 脚本分层撰写及多语种翻译本地化。
* **提示词优化大模型**：**StepFun step-3.7-flash**，专用于将粗糙的视频提示词深度扩展为富含材质、光影及运镜的专业分镜 Prompt。
* **语音合成大模型**：**StepAudio 2.5 TTS** (`stepaudio-2.5-tts`)，提供包含呼吸声的超写实情感化语音合成，支持音量和语速的多级变轨。
* **物理视频生成大模型**：**Seedance 2.0** (`doubao-seedance-2-0-fast-260128`），支持高度逼真的物理细节运动合成、首帧控制及高分辨率的图生视频。

### 2. 前后端架构与开源组件
* **后端 BaaS 云服务**：**Supabase** (集成 PostgreSQL 数据库、行级安全机制 RLS、Deno 边缘计算 Edge Functions 以及安全云 Storage)。
* **前端框架**：**React 18.3.1 + Vite 5.4.1 + TypeScript 5.5.3**。
* **UI/UX 设计系统**：**Tailwind CSS 3.4.11 + Radix UI + shadcn/ui + Framer Motion** (提供了精美的毛玻璃态主题切换及波浪型文字动态增强交互动效)。
* **MCP 服务通信框架**：**Python FastMCP + httpx + python-dotenv + asyncio** (支持 streamable-http 与 stdio 双模式数据通路)。
* **开发辅助**：**Biome** (超快 Lint 校验), **Recharts** (可视化数据看板)。

### 3. AI Coding 开发工具
* **Antigravity (Google DeepMind)**：本次项目的深度开发伙伴，辅助进行了复杂的 MCP 协议通信设计、完成了多层异步工具的逻辑封装，并通过快速的反射调试解决了 JSON 导入时 Schema 不兼容的错误。
