# 任务中心新协议接入

日期：2026-10-21。修改范围为前端任务中心、发布 API 类型与状态映射；无数据库迁移、无新服务端写入口。

## 行为

`/task-queue` 统一读取：

- `video-jobs` list：本人关联计费的视频任务，公开状态、进度、积分及成片。
- `production-jobs` list：图片、封面、剪辑渲染及通用后台任务。
- `platform-publish` list：发布排期、上传、平台处理/审核、公开成功、失败、未知与取消。

生产发布任务与发布记录按 job_id 去重；有平台记录时以其审核/公开状态为准。没有发布记录的通用 completed 只显示“发布结果待同步”，不能当成已公开。视频 submission_state=unknown 或非终态 needs_attention 显示“待核对”，保留原消费，不允许直接重发。

列表显示服务端真实进度、任务ID、创建/计划时间、原消费状态、错误与对应作品/工程入口。提供类型、状态、搜索筛选；页面可见时每10秒、回到窗口时刷新，避免依赖旧 Realtime 字段与 publication。最近记录数量受各业务API list限制，不是全量历史统计。

单项刷新走对应新query/list。旧 `ai-assistant.retry_video_job`、DataAPI直接删除任务、固定65%进度及虚构并发/重试上限已移除。任务历史保留在后台；失败任务进入创作或原工程确认后创建新请求，新消费由业务服务决定。此修复没有新增“一键重发原任务”API。

待提交发布可调用既有 platform-publish cancel，服务端负责竞争条件。取消仅在 ok=true 后显示成功；409/网络失败保留记录并重新核对。运行、审核、未知任务不显示取消入口。

各来源分别处理失败，保留上次成功记录，显示具体错误；错误或不兼容返回不能伪装空列表。账户切换/组件卸载隔离迟到结果，加载与操作防重复，移动端筛选与长标题可换行。

## 验证与部署

- `npm run test:task-center`：8项状态、计费、发布去重、进度、未知保护与当前路由测试。
- `tests/browser_task_center.mjs`：隔离API夹具下真实页面交互，覆盖三来源合并、类型/状态/搜索、查询成功/失败、取消冲突/成功、部分接口故障与旧返回格式、空状态；390px无横向溢出，无旧重试/DELETE/创建调用。
- 现有视频与生产任务回归、类型检查、Biome/项目规则与生产构建。

浏览器脚本可通过 PLAYWRIGHT_MODULE、CHROMIUM_PATH、UI_TEST_URL 指向本地Playwright及隔离Vite，后端夹具地址固定为 `https://ui-fixture.example`，不连接生产资源。

当前最新版前端依赖已存在的新业务函数；云端需匹配 `video-jobs`、`production-jobs`、`platform-publish` 与00035/00036。本轮未部署云端。其他作品/素材/头像页面遗留问题不属于此次任务中心修复。
