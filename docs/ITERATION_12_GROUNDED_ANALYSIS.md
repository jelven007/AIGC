# 真实素材分析、口播与高光 MP4

日期：2026-10-21。增量迁移 `00041_grounded_video_analysis.sql`。本地实现与受控验证，云端和真实供应商尚未验收。

## 用户功能

- `/live-highlight`、`/style-copy`共用真实视频分析工作台，上传本人私有MP4/MOV/WebM；最大100MB、10分钟，长直播需分段。旧平台播放页不能作为已读取视频。
- FFmpeg读取真实时长与音轨，抽取8个均匀时间画面并保存SHA-256源指纹；音轨输出16kHz单声道WAV，最多20MB。抽帧不是镜头边界检测。
- 直播高光需要OpenAI ASR协议的`whisper-1`有效时间段。模型只选字幕段号；服务端由实际段首/段尾计算时间，校验不重叠、不越界、每段最多120秒。不生成观看人数、互动峰值或订单数据。
- 选择高光创建独立FFmpeg渲染任务，按源素材真实时间裁剪，输出720p竖屏H.264/AAC MP4，保存到作品库。取代文本清单冒称视频导出和无素材剪辑导入。
- 风格报告依据真实抽帧与转录，保存私有历史记录，支持将建议带入脚本/视频创作；仅保留模型编辑评分。BPM、声画同步、完整转场和字幕覆盖率未测量，不应从抽样推断实测百分比。
- 分镜与A/B变体改为真实结构化文本模型创作，校验字段/数量，A/B返回完整脚本、英文提示、实验变量与假设，预测完播/点击率为缺失。
- `/emotion-analysis`只展示有效模型逐句建议，索引、类型、强度范围校验，原文和颜色由服务端固定；取消预置结果、随机降级与错误后的成功提示。用户输入可带入语音工作台。
- 网页卖点经配置的Reader真实读取正文（最多2MB、提供15k字符给模型），空正文/无效结果抛错，由原流水补偿，不把错误提示作为卖点。竞品旧入口不再写入LLM生成的假指标；授权数据供应商仍待接入。

## 任务架构与契约

`production-jobs create kind=analysis`使用`video:create`，读价格`analysis-price`及查询/列表使用`jobs:read`。`input={mode:live|style,title,source_url,confirmed_credit_cost}`，请求UUID必须固定。服务端绑定不可变文本和ASR版本；普通查询只返回结果/模式，不返回租约与原始识别证据。

事务：账户锁→原请求核对→每人3个未结案分析任务→配置/确认价格/余额→创建及预占。默认6积分，实际价格从数据库读取；价格变化409、队列满429、配置或分段模型缺失424，创建失联503保留原回执。所选全部片段的请求在提交前一起保存，恢复用原UUID。当前render默认免积分，后续价格调整必须联动页面确认。

两个执行器共用队列但按阶段隔离：

1. FFmpeg Worker只领取`analysis_prepare`（映射analysis且无evidence）。专用租约生成本任务9个上传对象（WAV及8帧）；业务API核对实际对象大小、帧时间、源指纹和时长。
2. `prepared`事务保存证据并释放租约，状态回pending。普通生产Worker只能领取已有预处理证据或结案证据的analysis。
3. 原ASR版本识别→持久化正文/分段→原文本版本处理画面和转录→结构化结果校验→持久化结果→结案。数据库核对源引用、指纹、时长、文本/ASR版本；风格历史与结案原子写入。
4. 模型POST响应未知或执行阶段租约过期进入unknown，不重新付费提交。已保存识别/结果/结案证据可恢复。明确模型拒绝、无效分段或不可交付分析结果按原流水返还一次。

180秒租约、30秒心跳沿用生产链。两段Worker轮转避免饿死。结案/退款不改变已确认的证据。

旧`ai-assistant analyze_style/extract_highlights`和`phase3-assistant analyze_live_highlight`返回410并指向新队列；删除旧随机处理器。AI入口所有操作需认证，缓存命名空间升级避免命中旧伪造分析结果。`analyze_traffic`只生成参数建议，未接入观测指标时返回null；旧分析看板对null的处理在后续数据口径迭代中继续统一。

## 本地验证与边界

- 5项真实PG事务：并发一次收费、价格拒绝、配置停用后恢复、队列配额、两段领取隔离、模型提交崩溃unknown、原退款一次、源指纹与风格私有归档。
- 4组真实模块协议：字幕边界/越界/无时间戳、原句、签名帧及WAV、不可变模型版本、结案故障不重复模型、未知受理、旧直播410、匿名和播放页拒绝、9对象上传与阶段权限。
- 2项真实FFmpeg：抽帧JPEG、实际SHA-256、16kHz/单声道、1.2秒竖屏MP4编码、无音轨与取消/无素材拒绝。
