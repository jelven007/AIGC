# ADR-002：按媒体交互职责拆分生产界面

日期：2026-10-31；状态：首批切片已实施，后续按共同修改边界推进。对应O06/D2。

保留页面编排、原账号边界和已有history/persistence/clock/cache Hook。首页作品卡片与剪辑器媒体库分别成为独立组件，组件持有预览/筛选/选择交互；保存、原工程及任务状态仍由原生命周期负责。共享组件不导入页面。

替代方案为一次迁移全部大页面或引入新状态框架：没有实测收益，迁移会同时影响保存和恢复，因此不采用。代价是大页面仍存在，当前切片不是全面重写。

前端维护者负责切片，仓库维护者复核依赖，具体人员待登记。验证为零循环/反向依赖及保存、撤销、原UUID、刷新、切账号、录音浏览器回归。单切片可恢复原组合并运行同样验证，无数据迁移；不同时改资金或任务协议。重复修改证明新的共同职责后再扩展Inspector/时间轴/预览、数字人及脚本。
