# ADR-004：先保留版本精确检索，再按规模评估ANN

日期：2026-10-31；状态：保留00066，比较条件已登记。对应O11/D4。

当前有账号范围、配置/维度/正文版本和引用约束，200条/账号、24块/条目有界。历史同数据隔离PG显示00066读取优化，尚无真实API超预算证据，因此不立即改ANN。

代价是扩大数据后仍需精确计算，旧测量不能推导生产SLA。数据维护者负责同样本基线，后端复核权限/引用，具体人员待登记。实测持续超已登记预算后比较pgvector候选的召回、P95、写入代价、维度/索引迁移及源删除。

质量、引用或权限退化就停止候选；旧索引/版本保留，切回精确查询无需改正文事实。历史迁移不重写，扩大范围采用新增迁移及目标恢复接受。
