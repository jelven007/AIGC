# ADR-003：数据库继续承担任务与资金权威

日期：2026-10-31；状态：保留现状，演进条件已登记。对应O11/D3。

已有原UUID、租约fencing、公平预算、UNKNOWN及原流水。保持受限RPC中的任务创建与积分事务、独立生产/维护及媒体执行。立即引入外部broker会增加双事实源、重复受理和恢复成本，当前没有目标吞吐证据支持。

代价是领取、状态及资金共享DB负载。后端维护者负责一致性，运维负责测量，具体人员待登记。只有同数据重复测量证明领取/锁等待是瓶颈时试通知broker；原状态仍在DB，重复通知不得重复提交或收费。

候选必须通过公平、并发资金、过期租约、UNKNOWN重启及原请求恢复测试。退回DB轮询只停通知消费者，不删除任务/流水；保持原UUID及执行租约。生产容量尚未接受。
