# ADR-005：供应商按版本退出，平台先恢复后切换

日期：2026-10-31；状态：保持原目标，退出条件已登记。对应O13/D5。

原官方目标持有身份、账和Storage；火山/自托管为独立目标。管理访问失效不等于数据可丢弃，改URL也不等于迁移。先接受原目标；模型按版本adapter切新任务，旧受理继续原账号/配置/历史key_id查询。

立即全面迁平台可能获得新的运行方式，但Auth UUID、原现金/UNKNOWN、对象引用及OAuth快照迁移成本高，当前缺目标恢复和成本证据，因此不采用。

平台集成维护者负责旧受理核对，发布/运维负责隔离恢复，财务复核原账，具体人员待登记。重新评估由真实费用、运行限制或服务退出驱动；先隔离恢复并验收身份/RLS/Storage/原任务，再冻结新写入、对账、切入口。

回退前先核对切换后新增写入与外部受理，不允许两边同时派发。保留原包、完整历史密钥和恢复回执；不删除旧任务、倒改终态或重放未知POST。
