清除第一轮验证中发现的 23 处前端 TypeScript 错误，并修复微信下单函数在 Deno 严格检查中的 5 处类型错误。

- 分析页样例补齐 `VideoProject` 的产品、提示词、分镜、素材及风格字段；建议列表使用空数组。
- 数字人类型补充可选说明字段；内置样例补齐视频地址与创建时间。
- 脚本样例改用编辑器实际读取的 `dialogue/prompt` 字段，避免台词和提示词空白。
- 风格分析样例补齐摘要与标签。
- 商品图片 Ref 对齐 React 18 类型，删除按钮按处理函数实际签名调用。
- 音频 Base64 解码数组显式声明为 `BlobPart[]`。
- 微信 SDK 响应按未知外部数据检查 `code_url/message`，异常按 `Error` 判定。

- `npm run typecheck`：通过。
- `npx biome lint src`：通过，检查 150 个文件。
- `npm run build`：通过；仍有入口包体积与动态导入提示，后续进行分包优化。
- Deno 2.2.6 对微信通知、微信下单、支付宝通知和支付宝查询四个函数的检查：通过，使用真实 npm 依赖类型。
- 第一轮微信 WebCrypto 测试也在原生 Deno 中通过。
