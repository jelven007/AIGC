# 凭据历史清理

当前主线继续使用私有初始化配置：账号密码、模型服务密钥和支付密钥
只在受控运行环境保存。浏览器只读取公开连接参数和用户会话，文档不记录凭据原值。

本次清理从本仓库可达主分支、标签、归档和提交说明中移除确认泄露的
历史密码重复值及模型服务密钥，保留提交拓扑。重写会改变提交 SHA；
已经发布产物的旧哈希仍只证明其原始字节，不能冒充脱敏副本或新的源码身份。

受影响的 v1.0.0 旧源码附件需撤下，并提供带独立身份和新哈希的脱敏副本。
v1.0.1 发布源码经原 SHA-256 核验并解包检查，未命中本次确认的泄露值。
标签改指脱敏历史后，原发布记录应注明原构建身份，不能称为新 tag 的精确构建。

新检出应基于清理后的远程引用。已有本地开发修改须单独保留并迁移，
不要从旧克隆强推或生成未经检查的恢复包。
GitHub 缓存、他人副本和已运行服务需要分别处理；删除公开原值不让密钥自动失效。
已暴露且仍有效的密钥应由持有者在受控环境轮换，本次源码清理不擅自修改运行凭据。
