# 页面视觉与导航规范

类型：reference。读者：前端与测试维护者。核验日期：2026-11-01。责任：前端维护者。来源：`apps/web/src/index.css`、`MainLayout.tsx`、共享 Card/Dialog 组件及实际浏览器验收。每次页面或共享样式变动后复核；标题、页头或控件规则变化未同步即过期。

采用 uicraft 的 normalize、typography、spatial-design 指导，沿用现有暖橙品牌色与深色主题，以清晰文字层级、统一表面和固定间距组织页面。

| 项目 | 标准 |
| --- | --- |
| 公共顶栏 | 品牌区与右侧顶栏共用48px高度；品牌图标24px，导航取消“主要功能”分组标题并上移；剪辑页显示同一顶栏 |
| 页面主标题 | 普通业务页使用 h1，24px、600字重、1.1行高；桌面与手机一致，无旁置图标、emoji或彩色竖线 |
| 区块与卡片标题 | 默认16px、600字重；列表条目、工具名称可用14px，导航分组可用12px |
| 弹窗标题 | 默认18px、600字重；剪辑工具紧凑面板可保留专用字号；标题内及紧邻标题的位置均不放装饰图标 |
| 说明文字 | 14px、1.4行高、muted-foreground；主标题与说明相距2px |
| 页面留白 | 一级页桌面24px左右、16px顶部、32px底部；手机16px左右、12px顶部、24px底部；区块默认24px间隔 |
| 一级页头 | 使用共享 PageHeader，左侧标题与说明，桌面操作区在右侧与标题顶部对齐，距正文边界24px；手机操作区在说明下方4px，左对齐并按8px间距换行；数字人库的资源切换保持右对齐 |
| 页头控件 | 共用 Button；32px高、14px文字、8px圆角，图标与文字间距8px；触屏44px高，纯图标按钮44px宽；主要操作用默认样式、辅助操作用outline，不夹入非操作徽章 |
| 全局操作按钮 | 以工作台“视频生成”控件为准：桌面高度上限32px、触屏44px；默认/sm/lg共用32px，小于32px的已有桌面紧凑按钮保留。原生按钮、Button/asChild链接、Tabs、Select触发器、弹窗Portal、登录与营销页均适用；取消垂直padding防止文字溢出，触屏图标目标至少44px宽。复选框、单选框、开关与滑块保持各自指示器尺寸 |
| 窄屏公共顶栏 | 360px及以下品牌图标20px、完整品牌文字12px，左右留白8px、控件间距4px；保留44px触屏按钮，使导航、通知、个人中心和退出按钮全部处于视口内 |
| 表面与边框 | 卡片统一使用 card/border token、12px圆角；模块色用于导航、工具入口、选中状态和操作反馈 |
| 图标范围 | 保留导航、按钮、输入辅助、工具入口与独立状态提示的功能图标；不放进页面、区块、卡片、弹窗标题 |
| 响应式 | 操作区可换行，长标题可折行；禁止靠隐藏标题或截断导航文字解决溢出 |
| 专用布局 | 工作台和剪辑沿用统一一级页头，正文保留创作配色和画布布局；剪辑工作区高度为动态视口减48px顶栏。工作台宣传标题是h2，页面h1是“工作台”。营销页保留自身层级；同样执行标题无图标规则 |

数字人库页头右侧用两个可键盘操作的 Button 切换资源库，以 `aria-pressed` 表示选中状态；上传头像只在数字人内容区右上角出现，模板库不显示。下方筛选、搜索与上传共用一排工具栏，与页头资源切换共用 `--page-control-height`：常规32px、触屏44px，顶部与底部均对齐。桌面筛选标题与224px侧栏同宽，搜索框与列表内容起点一致；窄屏筛选按钮用带中文可访问名称的图标显示，保留搜索空间。语音与数字人工作台与页头同宽，不重复叠加外边距。

AI工具箱主文字是指向 `/ai-toolbox` 的链接，点击一次进入工具箱；箭头按钮独立展开/收起子菜单，并以 `aria-expanded`、`aria-controls` 和中文可访问名称表达状态。手机导航后关闭抽屉。不得重新添加「查看全部工具」的重复入口。侧栏保持168px、六个汉字文字区，长名称完整换行。

工作台工具卡片与个人中心统计卡片使用路由链接，保留完整标题、说明或数值；操作按钮采用紧凑尺寸。上下排列的比例、字体与剪辑面板按钮需保证内部图形、文字在32px内完整显示。

检查入口：`pnpm run test:heading-style` 扫描所有 TSX 标题；`pnpm run test:navigation-style-ui` 通过真实登录、鼠标与键盘操作验证主入口、独立展开、手机关闭、工具筛选和页面尺寸。后者从 `UI_ADMIN_FILE` 读取源码外私有凭据，并使用 `UI_TEST_URL` 指定环境；无凭据时不运行真实环境测试。当前产品固定深色主题，浏览器验收记录深色显示；不得据此宣称浅色主题已完成交互验收。

`pnpm run test:page-headers-ui` 使用隔离内存后端和真实渲染页面，测量39个侧栏、工具箱与顶栏入口在1440/1024/390/320px的标题起点、48px公共顶栏、右侧控件对齐与尺寸，检查管理员/普通用户配置入口和44px触屏目标，并验证新建、刷新、资源库切换、上传位置与剪辑工作区高度。设置 `PAGE_HEADER_BEFORE` 可对比该目录的 `geometry-before-{width}.json`，核验页头高度为调整前60%～80%；触屏仍以44px可点击尺寸优先。`test:browser` 已纳入此检查。

同一浏览器检查覆盖上述39页全部操作按钮、工作台各模式、剪辑工具面板、商品/头像/API Key/剪辑保存弹窗、匿名登录/密码重置/营销页，实测桌面≤32px与触屏44px。`BUTTON_HEIGHT_EVIDENCE`指定尺寸JSON输出文件；`BUTTON_HEIGHT_BASELINE=1`仅采集修改前尺寸。

上线验收须分别覆盖开发、本地自托管、ECS；浏览器证据与源码/载荷摘要核验互相独立。受套餐权限限制的页面，真实环境只验证当前账号可访问状态；其内部标题仍由全源码扫描覆盖。
