# 页面视觉与导航规范

类型：reference。读者：前端与测试维护者。核验日期：2026-11-01。责任：前端维护者。来源：`apps/web/src/index.css`、`MainLayout.tsx`、共享 Card/Dialog 组件及实际浏览器验收。每次页面或共享样式变动后复核；标题、页头或控件规则变化未同步即过期。

采用 uicraft 的 normalize、typography、spatial-design 指导，沿用现有暖橙品牌色与深色主题，以清晰文字层级、统一表面和固定间距组织页面。

| 项目 | 标准 |
| --- | --- |
| 页面主标题 | 普通业务页使用 h1，24px、600字重、1.4行高；桌面与手机一致，无旁置图标、emoji或彩色竖线 |
| 区块与卡片标题 | 默认16px、600字重；列表条目、工具名称可用14px，导航分组可用12px |
| 弹窗标题 | 默认18px、600字重；剪辑工具紧凑面板可保留专用字号；标题内及紧邻标题的位置均不放装饰图标 |
| 说明文字 | 14px、1.6行高、muted-foreground；主标题与说明相距8px |
| 页面留白 | 一级页桌面24px左右/顶部、32px底部；手机16px左右/顶部、24px底部；区块默认24px间隔 |
| 一级页头 | 使用共享 PageHeader，左侧标题与说明，桌面操作区在右侧与标题顶部对齐，距正文边界24px；手机操作区在说明下方16px，左对齐并按8px间距换行 |
| 页头控件 | 共用 Button；40px高、14px文字、8px圆角，图标与文字间距8px；触屏44px高；主要操作用默认样式、辅助操作用outline，不夹入非操作徽章 |
| 表面与边框 | 卡片统一使用 card/border token、12px圆角；模块色用于导航、工具入口、选中状态和操作反馈 |
| 图标范围 | 保留导航、按钮、输入辅助、工具入口与独立状态提示的功能图标；不放进页面、区块、卡片、弹窗标题 |
| 响应式 | 操作区可换行，长标题可折行；禁止靠隐藏标题或截断导航文字解决溢出 |
| 专用布局 | 工作台和剪辑沿用统一一级页头，正文保留创作配色和画布布局；工作台宣传标题是h2，页面h1是“工作台”。营销页保留自身层级；同样执行标题无图标规则 |

AI工具箱主文字是指向 `/ai-toolbox` 的链接，点击一次进入工具箱；箭头按钮独立展开/收起子菜单，并以 `aria-expanded`、`aria-controls` 和中文可访问名称表达状态。手机导航后关闭抽屉。不得重新添加「查看全部工具」的重复入口。侧栏保持168px、六个汉字文字区，长名称完整换行。

检查入口：`pnpm run test:heading-style` 扫描所有 TSX 标题；`pnpm run test:navigation-style-ui` 通过真实登录、鼠标与键盘操作验证主入口、独立展开、手机关闭、工具筛选和页面尺寸。后者从 `UI_ADMIN_FILE` 读取源码外私有凭据，并使用 `UI_TEST_URL` 指定环境；无凭据时不运行真实环境测试。当前产品固定深色主题，浏览器验收记录深色显示；不得据此宣称浅色主题已完成交互验收。

`pnpm run test:page-headers-ui` 使用隔离内存后端和真实渲染页面，测量39个侧栏、工具箱与顶栏入口在1440/1024/390/320px的标题起点、右侧控件对齐与尺寸，检查管理员/普通用户配置入口和44px触屏目标，并验证新建、刷新、工作台切换与跳转操作。`test:browser` 已纳入此检查。

上线验收须分别覆盖开发、本地自托管、ECS；浏览器证据与源码/载荷摘要核验互相独立。受套餐权限限制的页面，真实环境只验证当前账号可访问状态；其内部标题仍由全源码扫描覆盖。
