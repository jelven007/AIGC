# 运营与客服手册

类型：how-to，operational。读者：运营、客服、财务和模型管理员。责任：运营维护者。核验：2026-11-01。来源：apps/web/src/pages/operations/OperationsPage.tsx、apps/web/src/api/operations.ts、supabase/functions/operations及数据库事务。每次权限/账务/工单变化或30天复核；操作与真实范围不符即过期。

## 用户上手

用户登录后核对本人资料与余额；余额读取失败重试，不解释为零或免费版。准备有权素材与真实商品信息，选择已启用模型、规格、音色并确认价格。分镜草稿仅在原账号有效数据恢复后提示，提醒为浮层；生成结果保存未知时恢复原请求，不重新付费生成。

商品页统一搜索/筛选/列表/卡片，缺失价格、币种、库存、销量保留为空。来源导入后由用户确认，导入不等于视频已生成。知识为检索资料，不宣传模型已训练或固定效果提升。

任务提交保留原UUID，可离开页面；任务/作品页读取后台结果。完成记录缺成片核对原任务和Storage。预览并检查文字、声音、事实与权利后导出或逐账号发布；发布以真实published终态为准，部分成功不重发。

模型接口只管理16模型槽与不可变版本，第三方集成独立管理4个连接槽。经营方确认供应商权限、价格和实际效果后才启用；页面数量不证明模型、支付、短信或平台已经接通。

## 操作责任与权限

| 责任 | 操作 | 证据 |
| --- | --- | --- |
| 模型管理员 | 配置/版本/禁用和实际生成接受 | 原槽/配置版本、样本、供应商用量 |
| 客服/运营 | 按客户范围查看详情、分配工单、公开回复/内部备注、风险处理 | 原用户/任务/订单、版本、UUID及处置结论 |
| 全范围运营 | 租户所有权/成员/预算/启停 | 服务端范围、原版本和持久回执 |
| 财务 | 两渠道原申请退款、原调用现金凭证与冲销 | 渠道回执、币种整数金额、原账单/指纹 |
| 审计 | 只读核对 | 权威流水和源记录 |
| 运维 | 调度、告警、升级与恢复 | 当轮运行/快照/验收回执 |

会话过期或权限变化停止写入；版本冲突先重新读取，503/未知受理恢复原UUID。客服不索取密码、完整JWT、service_role或模型密钥，不直接改数据库余额。发布截图隐去真实账号和客户数据。

## 状态与补偿

| 状态/反馈 | 处理 |
| --- | --- |
| 排队/处理中 | 查原租约、配置与年龄；收起进度不表示取消 |
| unknown/待核对 | 保留预占与原证据，核对原供应商请求；不重提或盲退 |
| 明确失败/未启动取消 | 按原流水返还积分，核对关联，禁止再次人工加分 |
| 完成不可播放 | 查真实归档/签名/Storage，不凭截图判生成或退款 |
| 付款成功未到账 | 原交易验签/查单、权益和幂等入账核对 |
| 退款处理中/ABNORMAL | 恢复原渠道/UUID；签名SUCCESS才回收权益，CLOSED表示未到账 |
| 配置/价格409 | 刷新当前配置并重新确认；旧受理任务保持原版本 |

工单本人最多10未结案。租户暂停阻止新计费/共享签名，旧签名按原期限；风险结论与计费限制独立，原退款与工单仍可处理。声纹撤销与知识删除按引用/用途/outbox和后台供应商回执执行。

## 经营指标与日常检查

每日核对最老unknown、排队/转存失败、支付权益差异、供应商配额、告警时效及新工单。超过三分钟未采集的告警标记陈旧，不能认为无故障。

任务完成率按同一创建cohort计算并列pending/unknown；已决成功率不能代替整体完成率。应用积分退款与现金退款分别统计。每条接受成片成本包含该批所有供应商调用、失败、存储/带宽和人工核对，缺现金保持未知。CTR=点击/曝光、CVR=转化/点击；ROAS扣退款且按来源/币种，不等于利润ROI。历史压测不代表付费用户留存或商业效果。

每周按固定窗口汇总质量、成本、留存和故障原因。发布按配置版本观察，宣传只用已核验界面/成片；正式收款、SMS/邮件、平台权限和商业供应商需独立验收。经营方案与资金细则见[商业化](../plan/商业化.md)、[支付](../plan/支付.md)；技术故障转[运行手册](RUNBOOK.md)，环境状态见[当前状态](../CURRENT_STATE.md)。
