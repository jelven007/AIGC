# 画布功能设计

日期：2026-11-18。状态：用户已批准，已实现并完成隔离验证；生产发布待授权。类型：design。读者：产品、前端与后端维护者。责任：本次画布功能维护者。复核条件：用户调整首版范围，或画布、媒体任务、保存协议发生变化时更新。

## 目标与参考依据

用户要求：参考 https://www.liblib.tv/ ，增加画布功能。

将文字、图片、视频与音频放在一个可自由组织的创作空间，减少在素材列表和生成页面之间来回切换。首版以“节点式无限画布”为核心，沿用本项目深色主题、暖橙主色、导航和模型接口。

2026-11-18 实际浏览参考站点得到的依据：

- 网站显示“LibTV - 专业视频创作工具”，首页提供“新建画布创作”。
- 公开导航包含项目、资产、LibTV 画布、LibTV Agent 和 LibTV 3D-BOX。
- 公开功能入口包含视频生成、图片生成、音频生成、剧本生成与智能剪辑。
- 点击“新建画布创作”出现登录窗口。未登录编辑器的内部操作与保存行为没有得到验证，不将本方案中的节点、连线或快捷键描述为参考站点已核实的功能。
- 从首页“帮助信息 → 使用教程”访问了[LibTV 使用指南](https://resonate.feishu.cn/wiki/Loxfw6XHziYRk0kKzdjcFfp9nhb)，公开可读取部分以官网、插件和更新入口为主，未取得编辑器内部交互证据。

以下节点组织、连线规则和保存方式是结合本项目提出的实现设计。

## 方案取舍

| 方案 | 用户可获得的能力 | 代价与边界 |
| --- | --- | --- |
| 节点式无限画布（推荐） | 组织多种素材、编辑文字、连接参考关系、图片生成、把素材送入现有视频工作台 | 需独立画布状态、项目存储和节点任务恢复；适合作为单次功能交付 |
| 多图层图片编辑器 | 拼图、文字排版、图层叠加与图片导出 | 更适合海报与封面制作，不能覆盖多媒体创作空间；现有单图编辑可继续承担蒙版编辑 |
| 完整自动化工作流引擎 | 按连接关系自动执行剧本、图片、视频与音频任务 | 涉及依赖调度、并行任务、失败恢复和跨任务计费，需另行设计 |

推荐第一种。画布首先负责组织素材和发起明确的单节点操作；连接本身不自动提交收费任务。

## 首版用户流程

1. 从侧栏“创作画布”进入 `/canvas`，查看自己的画布项目。
2. 点击“新建画布”，创建具备稳定 UUID 的空白工程并进入 `/canvas/:canvasId`。
3. 从左侧工具栏添加文字、图片、视频、音频或分组，也可从已有素材库选择或上传媒体。
4. 拖动节点组织内容，连接文字与图片，编辑图片节点的提示词并主动点击生成。
5. 图片生成的进度与结果直接出现在原节点中；可以下载结果、加入素材库，或使用它继续生成另一张图片。
6. 选择图片或视频节点，点击“用于视频创作”，将已确认的媒体引用送入现有工作台。视频制作仍由现有视频任务系统承担。
7. 画布自动保存，顶部提供手动保存、项目管理和工程文件导出；离开后可从原项目继续。

## 布局与交互

保留现有 48px 公共顶栏和六字导航文字区。新增“创作画布”入口，归属创作区域。画布页面使用专用布局，不在长列表页面中嵌入编辑器。

| 区域 | 内容 |
| --- | --- |
| 页面顶栏 | 项目名称、保存状态、撤销、重做、素材库、保存、导出工程 |
| 左侧工具栏 | 选择、平移、文字、图片、视频、音频、分组 |
| 中央视区 | 点阵背景、自由定位节点、参考连线、选择边框 |
| 右侧属性面板 | 当前节点名称、内容、媒体预览、提示词、模型能力、节点操作 |
| 视区右下方 | 缩小、比例、放大、适应全部内容、缩略导航 |

支持鼠标拖动节点、框选、Shift 多选、空格拖拽平移、缩放、适应全部内容、复制、删除、分组和解除分组。快捷键包括 V 选择、H 平移、Delete 删除、Ctrl/Cmd+Z 撤销、Ctrl/Cmd+Shift+Z 重做、Ctrl/Cmd+D 复制与 Ctrl/Cmd+S 保存。

输入框、文本域、弹窗和媒体播放控件持有焦点时不触发画布编辑快捷键。一次拖动结束形成一个撤销步骤，不为每个鼠标位移记录历史。画布缩放与平移不计入内容撤销历史。

手机保留完整画布视区，属性面板与素材库改为抽屉，工具操作满足 44px 触屏目标。控件不得依赖页面横向滚动才能使用。媒体节点可以缩放视图，但媒体播放器和文本编辑保持可操作。

## 节点与连线

| 类型 | 首版能力 |
| --- | --- |
| 文字 | 标题、可编辑正文，可作为图片生成提示词来源 |
| 图片 | 上传或选取素材、预览、下载、提示词、文生图及受模型能力约束的参考图生成 |
| 视频 | 上传或选取素材、播放、下载、送入现有视频工作台 |
| 音频 | 上传或选取素材、播放、下载 |
| 分组 | 命名分组、包含选中节点、整体移动、解除分组 |

连线规则：

- `文字 → 图片`：图片生成时使用连接的文字正文作为提示词来源。最多连接一个文字来源；来源为空时提示用户填写，不使用旧内容静默替代。
- `图片 → 图片`：使用来源节点当前完成的图片作为参考图。最多连接一个图片来源；模型不支持参考图或来源未完成时禁用生成并显示原因。
- 文字和参考图可以同时作为同一图片节点的输入。
- 拒绝自连接、重复连接和循环引用；删除节点同时删除相关连线。
- 视频和音频节点首版用于媒体组织，不展示尚未实现的自动生成或混音连接端口。
- 生成操作捕获当时的输入快照。生成期间修改上游文字或素材只影响下一次生成，不修改已提交任务。

原 `ImageEditCanvas.tsx` 继续承担现有扩图与局部重绘。首版新画布不重复建设蒙版画笔或图层合成导出器。

## 图片生成与现有业务衔接

复用 `useWorkspaceModels`、图片能力契约、`productionRequest`、`createProductionJob` 和现有任务查询机制。图片生成只提供已启用并具备相应能力的真实模型配置，显示服务端读取的积分信息。

新画布建立自己的节点任务适配层。现有 `useProductionJob` 的回执按工作台或视频工程保存，不能直接让所有图片节点共用同一个回执。画布回执使用“账号、画布 UUID、节点 UUID”隔离，并记录稳定 `request_key`、完整输入和任务 ID。

图片任务仍使用现有 `production_jobs` 协议。新建画布 UUID 不作为 `project_id` 传入图片任务，因为该字段引用视频工程。画布通过自身文档记录任务引用。

生成按钮点击前校验非空提示词、模型能力、参考素材与积分读取结果。提交结果不明确时恢复原请求，不创建新 UUID。重复点击不会重复计费。首版每个画布只允许一个未终结的图片生成任务，其他节点继续支持整理和预览；待确认任务不会被普通重试替换。

任务完成后只更新原节点的任务状态和媒体引用。节点已删除或画布已切换时，不创建复活节点，也不把结果写进别的项目；结果仍可在原任务中心恢复。复制节点不复制待执行请求或任务恢复回执。

“用于视频创作”通过现有工作台入口状态传递媒体引用，沿用账号检查和素材预览规则。图片成为参考图，视频成为参考视频；不因此自动提交视频任务。

## 数据与保存

新增独立 `canvas_projects` 表，而不是把画布工程标为完成的视频工程，避免混入作品、视频统计和已有剪辑列表。在当前最新 `00069` 后追加迁移 `00070_canvas_projects.sql`，历史迁移保持原样。

字段设计：`id`、`user_id`、`title`、`document`、`revision`、`created_at`、`updated_at`。文档包含 `schemaVersion`、节点、连线和视区；节点包含稳定 ID、类型、坐标、分组归属及类型对应的数据。任务引用与媒体引用保存在节点数据中。

- 数据库启用 RLS，只允许当前账号读取和修改自己的工程；客户端在请求前后复核账号并检查回执归属。
- 同一迁移接入现有 `sync_media_references`，使仍被画布使用的媒体受到引用保护。
- 云端保存使用版本比较；旧版本不能覆盖另一标签页已保存的新版本。冲突时保留当前本地内容并提供重载云端或另存工程。
- 内容更改后延迟约 800ms 自动保存，保存串行执行。若新修改发生在保存期间，上一版本确认后继续保存最新版本。
- 每次修改先写按账号与画布隔离的本地恢复副本，再进行云端保存。本地文档保留基础云端版本；只有版本一致才能直接恢复为后续编辑，版本不同进入冲突流程。
- 保存显示“有未保存修改、保存中、已保存、保存失败”，必须取得回执才显示“已保存”。本地存储失败或云端请求失败保留页面内容，提供重试和工程导出。
- 新建采用客户端稳定 UUID。创建响应丢失后按原 UUID 查询恢复，不创建重复工程。
- 保存稳定媒体路径，读取时由 `canonicalMediaTree` 与 `hydrateMediaTree` 转换并签名，不把短期签名地址作为持久化来源。
- 退出或切换账号后取消未完成的前端请求，清空内存节点、媒体缓存和恢复界面；不同账号的恢复副本不能串用。

“导出工程”下载带 `schemaVersion` 的 JSON，包含文字、布局和稳定媒体引用。它是工程文件，不宣称包含媒体二进制或具备跨账号媒体访问权限。导入验证格式、节点数量、有限坐标和连线；导入时重新分配节点 ID、丢弃任务回执并检查媒体权限。

删除画布只删除工程及其引用，不删除原素材，也不取消已经提交的生成任务。存在未终结任务时先提示后果，再确认删除。

首版限制：每个画布最多 200 个节点，正文与提示词长度按对应接口限制，序列化工程不超过 2MB。上传沿用已有素材协议；超限在操作前明确提示。

## 实现边界

采用 `@xyflow/react` 提供视区、节点拖动、选区、连线和分组基础交互，按当前包管理器更新依赖与锁文件。生成器、媒体播放器和属性面板保持独立组件，不将新功能继续堆入 `HomePage.tsx`。

计划模块：

- `pages/production/CanvasPage.tsx`：项目入口、画布页面编排。
- `components/canvas/`：工具栏、节点、属性面板、素材抽屉和项目管理。
- `types/canvas.ts` 与 `lib/canvasDocument.ts`：数据模型、验证、导入和连线输入解析。
- `hooks/useCanvasHistory.ts` 与 `hooks/useCanvasPersistence.ts`：撤销和保存。
- `hooks/useCanvasImageJob.ts`：画布内单节点图片任务与恢复。
- `api/canvasProjects.ts`：具备账号边界和版本回执的项目请求。
- `App.tsx` 与 `MainLayout.tsx`：懒加载路由、菜单及专用布局。

共享层不导入页面；没有新状态框架、通用自动化执行器或额外图像编辑引擎。

| --- | --- |
