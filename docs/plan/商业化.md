试点新增 [私有知识引用](../archive/iterations/ITERATION_14_KNOWLEDGE_RETRIEVAL.md)：索引默认2/查询1积分，实际供应商用量分账；要求测真实召回、事实一致性及吞吐再制定套餐配额。当前17槽/00043本地交付，不宣传模型已经学习或转化率自动增长，不把本地协议夹具作为正式商业验收。

00042 [观测实验](../archive/iterations/ITERATION_13_MEASUREMENTS_EXPERIMENTS.md)新增试点效果验证基础：签名来源、分源币种CTR/CVR/CPA/ROAS、匿名固定分组和预注册窗口/统计。自然播放不是广告曝光，扣退款ROAS不是利润ROI，显著差异不保证下一次投放获益。真实授权数据商/平台、分流、商品成本和试点规模仍未验收；不将固定提升、假获胜或模型概率作为付费承诺。

最新本地能力见 [素材分析迭代12](../archive/iterations/ITERATION_12_GROUNDED_ANALYSIS.md)：真实视频与口播分析、高光MP4、模型分镜与A/B创意。试点先验收画面/字幕准确度、实际计费/模型成本、切片可用性和后台恢复；不将编辑评分当经营预测，不销售未经数据授权的竞品指标。真实供应商、云端和现金退款仍待验收。

## 1. 核心定位与可销售范围

面向具备商品素材的商家、内容运营与小型团队，优先验证脚本辅助、真实视频任务和成片归档。付费依据是能够交付可接受作品、保持任务/积分可核对，而不是页面数量、模型数量或自动投放故事。

当前本地已交付私有商品/知识/素材、视频图片编辑/媒体、剪辑/多规格、多镜头合成、两平台逐账号发布、情报/签名实验及运营退款/告警恢复。最新源码00068/probe24，目标须重新核对差距、部署匹配全栈并验收供应商/商户/平台/SMS后按启用范围销售；本轮未重新访问官方或上线火山资源。

## 3. 单位经济与预算

每条人工接受成片成本 = 同批全部供应商调用成本（包含失败、未知和重试）+ 存储/带宽 + 支付费 + 客服/核对成本，除以人工接受成片数。不能只算成功任务或把返还积分等同于上游退款。

每月毛贡献 = 实际确认收入 − 同期可归属模型/基础设施/支付等直接成本；另列固定研发、运营与税费，不从积分充值额直接推出利润。套餐收入确认、未消费权益与现金退款规则需财务确定。

建成本台账：供应商、账号/配置版本、规格、报价日期/单位/币种、实际账单、失败收费、接受率、流量/储存、人工时间。价格采用场景预算测算，不写未经验证的“每条几分钱、毛利百分之多少”。

个人/团队UTC积分预算已有并发护栏，失败返还仍占当日预占；风险限制只阻止新计费。供应商现金限额、免费文本与FFmpeg/Storage成本另设；财务按原调用/配置/币种/账单行/指纹人工登记和追加冲销，未知成本不按零。临时禁用新任务仍保留旧版本凭据。
