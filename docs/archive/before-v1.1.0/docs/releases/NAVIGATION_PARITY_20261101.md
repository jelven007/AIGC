# 六字导航与本地、线上一致性验收

核验日期：2026-11-01。本次修复已同步开发入口、本地自托管和ECS，分别完成真实页面交互与部署摘要交叉验证。侧栏从256px收窄为168px，主文字区按六个汉字设置，中文回退字体另留2px字面余量；六字名称单行，长名称完整换行。

原v1.0.1回执中的“紧凑”只验证了36/40px行高，不能证明宽度符合要求。本次还补齐开发环境用户名登录能力标志，并修复手机侧栏快速关闭、重开后Escape不能关闭的问题；该失败流程修复后在开发、本地部署和线上部署分别通过。

页面测试使用实际开发与部署载荷。集成浏览器首先复现256px基线；因其没有视口调整工具，使用已有Chromium补充四种视口测试。部署页面通过仅本机QA入口转发，各自上游HTTPS均严格验证CA和主机名；只将公开runtime配置中的后端URL映射到对应同源QA入口，真实Auth、REST和函数请求仍进入各自实例，没有模拟业务响应或关闭TLS校验。
