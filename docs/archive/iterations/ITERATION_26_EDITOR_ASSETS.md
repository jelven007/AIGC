# 迭代26：真实资源、私有录音与音频编辑

00054与素材登记接口、资源/录音组件、render4及MCP58工具已在本地实现。验证包括真实PostgreSQL、PCM/FFmpeg和Chromium；这些结果不构成目标云端上线、商用资源交易或真实供应商验收。

## 素材与使用权

编辑器资源商城改为资源库，从当前账号私有素材和团队授权共享读取。移除静态商品、销量、评分、默认已购、模拟微信/支付宝购买、假版权曲目和演示工程注入。商业资源交易需要真实目录、许可证、价格、支付和授权交付，目前没有这些上线条件，不保留虚假成交入口。

音乐音效面板使用同一资源组件：实际audio文件、真实播放器、结束/停止/错误状态、最新签名URL、原音轨时长与时间轴添加。团队共享继续沿用00037的成员/共享权限；服务端导出再次验证素材访问，当前界面的已下载文件不代替授权检查。列表每页30条，私有接口最多100条；团队共享当前最多100条，更多共享素材的分页尚待扩展。

素材页与编辑器统一`uploadMaterialAsset`，上传前明确确认使用权。支持图片、视频和音频，单文件50MB；浏览器读取原媒体实际时长。每次请求在上传前保存原UUID、文件SHA256、名称/MIME/大小/扩展名、使用权及来源，路径为`本人UUID/uploads/请求UUID.ext`。存储上传不覆盖；响应丢失或对象已存在时只恢复原登记，重选相同文件复用原请求。浏览器回执最多20条；尚未上传的文件需要重新选择原文件。

`material-assets`新增JWT限定`register/list`。客户端传来的user_id/path/url不能决定归属，服务端生成本人路径和稳定对象引用。`register_material_upload`是service-only事务，按本人/原UUID锁串行化，核对实际Storage元数据中的对象大小和MIME，素材与回执一次写入。同键换参数冲突、尚未上传、类型/大小不符和清理中的对象均不登记成功。读取失败不显示为成功空列表。

`material_upload_receipts`保留原请求和使用权确认时间，RLS只让本人读取。素材删除将回执material_id置空，重放返回deleted，不能复活已经删除或清理的对象。正式materials引用继续受00051生命周期保护。文件SHA256与时长为浏览器测量；登记不会把客户端SHA256声明当成服务端字节校验，后续分析/渲染仍读取并验证实际媒体。使用权勾选是用户声明，不是版权机构证明。

## 录音与编辑

新增独立RecordingDialog。用户授权声音使用后，浏览器申请麦克风；实际MediaRecorder录制，支持停止试听、重录、失败保留预览及私有登记。限10分钟/50MB，关闭或卸载停止设备、释放Blob；保存时先上传登记，再保存包含新音轨的工程，随后更新时间轴。HTTPS/设备/麦克风拒绝有明确错误。刷新恢复已上传但登记响应丢失的原录音；尚未上传的本地录音不会跨刷新保存。

移除原音频面板的装饰波形和未写入音轨的“应用成功”。EditorAudioPanel按所选audio/video直接更新音量、速度、淡入淡出、半音、声像、降噪、混响、10频段EQ、回声与机器人调制，参数随tracks保存和恢复。波形来自原音轨PCM，在源裁剪/速度对应范围取60组峰，源文件超过10分钟或50MB不解码；这不是实时电平或多声道响度报告。

FFmpeg使用实际equalizer、40Hz双声道环形调制与180ms回声，参数由业务API与Worker分别校验，未知频段、增益越界和未知效果拒绝。音频淡变与声像原有功能继续使用。音调/机器人/回声及视频原声效果以导出成片为准；浏览器audio轨EQ与声像接入Web Audio，降噪/混响预览是近似效果，不能用浏览器试听代替成片验收。

画中画改为自己的图片/视频，按实际时长添加；移除演示素材、促销文案和替换全工程的假模板。隐藏/锁定写入轨道、刷新恢复，隐藏轨道不导出；预览区分图片/视频，暂停、播放和源裁剪跟随时间轴，不再自动循环。文字贴纸使用实际文字轨道，多个字幕/贴纸可共同预览；不将静态照片宣传为动态粒子。

## 架构与MCP

资源、授权上传、录音、音频编辑及媒体预览拆成独立组件，编辑器删除超过千行旧模拟代码。页面媒体缓存按账号和页面隔离、合并同源重复请求，单文件50MB、缓存/正在接收字节合计128MB；离开页面取消请求并释放Blob，不再使用跨页面无限全局缓存。限额统计不是浏览器总内存验收，解码/Blob拷贝仍有额外占用。

MCP新增`get_edit_prices`与`submit_edit_analysis`。后者必填mode/title/source/request_key/confirmed_credit_cost，可选project_id；source保留原片段id/type/url/start/duration/sourceStart/speed。价格与query_production_status沿jobs:read，创建同网页使用render:create；模型、价格、素材与工程归属仍由业务服务验证。实际SDK导出tools.json为58工具/18业务权限，没有开放支付或账号管理旁路。

- Chromium开发及独立压缩页面：实际播放器、团队503重读、原文件2.5秒时长、授权上传503后刷新同UUID恢复/单对象、音频参数保存恢复、实际MediaRecorder停止预览/入库/工程保存、390px。原字幕/节拍/人物恢复回归。
- TypeScript、Biome、项目规则、独立构建、正式配置构建、两Edge Deno检查。FFmpeg镜像重建后按render4领取。

运行`npm run test:assets`；MCP使用`npm run test:mcp`，UI为`tests/browser_editor_assets.mjs`和`tests/browser_edit_analysis.mjs`。浏览器接口是隔离夹具，麦克风是Chromium测试设备；没有向生产数据库写测试素材。真实使用需验证Chrome/Safari/移动浏览器、设备中断、长音轨内存、Storage MIME和大小元数据、共享撤销及目标吞吐。

发布范围00032–00054与全部匹配服务；production探针严格要求`version=15/required_migration=00054/render_version=4/edit_version=1`。先升级数据库/素材API/production API与调度，再启用匹配前端/MCP和重建FFmpeg；render3及更旧Worker领取前426，不消耗租约。最近官方云端证据仍00031/三旧函数，本轮没有部署回执。
