# 迭代30：作品入口与真实素材链路

日期：2026-10-22。数据库与运行协议保持00058、probe18、render4、edit2；本轮调整前端与material-assets查询接口。代码和隔离验证不代表目标环境已发布。

## 行为与架构

- 作品库使用当前账号范围、服务端名称/状态筛选、稳定排序与每页24项，保留标题编辑、封面、剪辑、发布、导出和删除入口。删除逐项核对返回结果，部分失败显示实际未删除数量；完成记录无媒体时禁用播放、下载、发布和导出。
- 压缩回归复现首次快速翻页被搜索初始化计时器重置，修复为条件变化时才延迟查询，查询尚未生效时禁用翻页；同名的已上传`Shopro.mp4`仍可正常播放，旧公开演示路径单独过滤。
- 删除进入测试账号时自动插入完成作品/素材的逻辑，以及内置A/B假变体、随机曝光/点击/转化、趋势和“正式投放成功”提示。统一进入已有真实对照实验与观测页面。
- 作品素材上传、封面上传和首页参考图片/视频/首尾帧全部复用原素材登记接口：先确认使用权，原文件指纹、实测时长和UUID写本地回执，登记响应未知后恢复原上传。不按选择文件总数显示成功。
- 素材支持图片、视频与音频分页；搜索在后台完整查询当前用户资料，并将`%`、`_`和反斜线按字面匹配。查询失败保留错误和重试入口。
- 私有读取使用当前账号签名。预览验证原媒体，下载实际读取文件并核对类型，签名失败和无成片不回退演示视频。账号作为组件边界，旧异步列表响应不能覆盖新账号；上传每个阶段重新核对当前身份。
- 首页从本人最近40个完成作品构建创作参考，复用原提示词和保存的来源/画幅/商品分类。缺失字段显示“未记录”，完整列表由作品库分页浏览。
- 提示词增强显示实际接收字符；完整流结束才提示成功，失败保留原输入，离页中止请求。手机端按钮具备可访问名称。
- 公开介绍页展示实际功能和流程；去除虚构用户评价、销量、直播互动、性能/成本承诺和旧宣传媒体。确认源码无用途后移除40个旧视频、封面与轮播图片（62.99MiB），历史数据库记录未删除。
