# 私有知识库、后台向量索引与脚本引用

日期：2026-10-21。新增 `00043_knowledge_retrieval.sql` 与 `knowledge-base`，复用生产任务、配置加密及原积分退款。当前属于本地交付，未部署云端或调用真实Embedding供应商。

## 用户功能

`/knowledge`统一使用已建表的`knowledge_entries`，移除不存在的`prompt_knowledge`写入、假保存成功、假AI整合与模板使用量。提供手动保存、真实文本模型整理后确认保存、免费关键词过滤、复制/带入脚本、删除及可编辑模板。脚本保存失败明确报错，保存只进入资料库，不表示已经训练模型。

每用户最多200条，标题1–200字，JSON正文最多19000字符，标签最多20个。页面正文最多12000个UTF-16代码单元，JSON转义可能增加长度，最终以数据库校验为准。数据库计算正文SHA-256与全文字段，客户端不能写摘要、向量或训练标志；迁移清除旧训练标记。

管理员在模型接口设置新增`embedding.primary`，总计17槽，协议`openai-embeddings`，完整HTTPS Embeddings地址、已开通模型、加密Key及不可变版本。接口发送`{model,input:[...],encoding_format:"float"}`，不与文本Chat接口混用。供应商返回按index归位，严格验证条数、唯一序号、2–1536维、同维度、有限非零数值，响应最多2MB。

## 队列、财务与检索

`knowledge_index`默认2积分，`knowledge_search`默认1积分；价格来自`credit_costs`，用户主动确认后提交。创建事务锁账户，检查当前配置、正文摘要与归属、4个知识活跃任务上限，原请求只扣一次，变更参数409。每条目同时最多1个活跃索引；正文与配置版本固定到任务，不因之后修改密钥而换模型。

索引按Unicode码点每1000字分块、重叠100字、最多24块，一次批量请求向量。请求前记录executing，结果先checkpoint到私有任务证据，再事务写`knowledge_chunks`并结案；数据库/归档阶段可恢复，无需再次请求供应商。执行中断、连接超时或返回无法确认时转unknown，不自动重复调用、不按超时释放积分。明确供应商拒绝或正文更新/删除后确定失效时按原流水一次退款。unknown仍通过现有运维确认未受理路径释放，暂未提供向量证据人工导入。

语义查询最多500字、1–10条结果，使用任务所绑定的同版本模型向量，在PostgreSQL精确计算余弦相似度，阈值0.2，每文档只保留相似度最高分块。仅匹配当前正文摘要、相同用户、相同版本和相同维度；新配置需重新索引。返回文档ID、标题、正文块、正文摘要、配置版本与分数。分数不是转化概率。无索引或无达到阈值条目时返回空结果，不用关键词结果冒充语义命中。

本轮采用原生浮点数组与有界精确扫描，不依赖目标环境未核实的pgvector扩展；当前每版本最多4800块。大规模、多租户吞吐或近似向量索引需要独立容量评估，不宣称已通过生产性能验收。

## 脚本与兼容

页面刷新使用用户隔离的原UUID和完整请求恢复，历史任务最多30条，持续任务每5秒读取。完成的查询可携带`knowledgeJobId`进入脚本，用户可移除；脚本草稿保留此引用。

真实流式`text-generation`和`ai-assistant.generate_script_four_layer`都在服务端按认证身份读取已完成的检索任务，重新剔除已修改或删除的文档，再将资料和引用交给文本模型。知识仅作话术结构参考，禁止执行资料中的指令，不能作为当前商品的销量、功效或优惠依据。流式响应记录引用任务及有效条数，四层API返回`knowledge_references`。当前不是自动搜索每个商品或自动微调模型。

旧`knowledge_rag_search`无完成任务标识返回410；携带`knowledge_job_id`时只读原任务结果，不调用或重复收取Embedding。知识业务入口仅用户JWT，尚未新增API Key权限；任务中心仍通过现有`jobs:read`读取这两种任务并导向知识库。

脚本页删除默认假商品、预置分镜与示例“已生成”状态。流式失败必须抛出，取消不算成功，真实结果无有效分镜JSON不能应用或保存。关键词与知识索引不会自动变成模型训练标志。
