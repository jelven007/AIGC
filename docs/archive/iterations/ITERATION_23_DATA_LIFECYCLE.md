# 迭代23：媒体留存、声纹撤销与知识副本删除

本轮本地交付00051与匹配API、Worker、页面和MCP。媒体TTL、声纹撤销和知识删除已有执行链；目标云端、真实Storage和ElevenLabs删除仍需验收，不能据本地测试宣称系统已经生产上线。

## 媒体对象

- 新增`media_references`，由数据库触发器维护商品、素材、作品、形象、封面、风格历史、情报目标/样本和任务的嵌套稳定URL引用；中文、百分号编码和签名URL统一为bucket/path。任务心跳引用未变时跳过索引重写。
- 活跃及unknown任务的payload/evidence/resolution保护输入；已完成分析的正式结果保护原视频和高光，其他已归档输出由业务记录保护。
- `enqueue_expired_media`每轮最多枚举100个对象：三个私有桶内、已确认用户路径、创建和最后修改均超过24小时、无业务引用且未排队。无归属旧对象不猜测删除，需人工核对。正式保存对象没有固定到期日。
- 引用保存、上传、删除与TTL以对象级事务锁串行化。清理已排队的新引用/上传被拒绝，墓碑持续保留；旧版遗留引用可以解除，存在引用的对象不被领取删除。
- 撤销直接Storage删除策略。素材删除事务校验实际bucket/path与素材匹配、保护其他引用、删业务记录并写outbox；生成文件旧下载地址同时从终态任务移除，计费回执保留。
- 删除队列采用独立UUID租约和到期校验，最多10对象，失败指数退避至一小时；旧Worker的迟到成功/失败不能覆盖新租约。

## 声纹撤销

`production-jobs`新增`revoke-voice`，需`voice_clone_id`和原`request_key`，绑定当前JWT用户；Key需`audio:create`。重复撤销同一声纹返回原状态，同键换声纹409。`voices`返回`revoked_at/provider_deleted_at`，不暴露供应商ID或凭据。

撤销事务锁账户、声纹和关联任务，立即阻断新创建及`executing`受理切换。未提交配音取消、原流水仅退款一次；供应商正在受理且结果未知的配音保留原积分及核对，不能因撤销盲目退款或重发。已保存音频证据的任务可以完成原归档，已生成文件继续保留。

声纹删除进入持久化队列，轮转Worker每次领取一个。使用创建时的不可变配置版本，调用ElevenLabs官方`DELETE /v1/voices/{voice_id}`，仅`status=ok`或明确`voice_not_found`确认删除；普通404、权限失败、超时和伪成功均退避重试。未知原配音受理未核对前不领取删除。成功回执清空供应商ID及克隆任务原始证据，页面显示实际删除状态。

参考：[ElevenLabs Delete voice](https://elevenlabs.io/docs/api-reference/voices/delete)。真实供应商账号权限、旧凭据、响应丢失恢复及声音删除范围需目标验证，不能将本地协议夹具算作供应商验收。

页面使用用户隔离的原UUID撤销回执，503/关页/刷新后恢复原请求；撤销音色从配音选择中移除，不提供重新启用。供应商删除异步，用户可以刷新查看。

## 知识副本

`knowledge-base`新增`delete`/`entry_id`，绑定当前用户；Key需`knowledge:write`，浏览器直接DELETE权限撤销。重复删除同条目可恢复响应；其他用户的条目不被修改。

条目及分块删除同事务清理索引任务正文、向量证据、结案快照与关联检索片段。未提交或已有确定响应的索引取消并返还原积分；提交未知索引标记unknown、清除正文、保留原流水等待用量核对。供应商晚到旧租约不能重新保存正文，检索结果写入时再次过滤当前条目及正文版本。升级同时修复旧版已删除条目的遗留任务副本。

删除影响应用内原知识及其索引/检索副本，不自动删除用户据此创作并单独保存的脚本，也不对外部文本/Embedding供应商的保留政策作删除承诺。

已完成/失败/取消任务超过七天后，每轮最多100条清理evidence/resolution及索引正文快照，保留任务状态/原请求/积分与正式结果。unknown及未结案任务不按TTL丢弃恢复证据。
