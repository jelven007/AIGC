# 架构对比与模型配置收敛

范围：比较原仓库、服务端视频改造及火山适配后的实现，补齐模型接口配置链路。当前基线为 `5ba7466`，火山资源创建与真实模型云端验收仍未完成。

## 架构对比

| 维度 | 原仓库 | 火山适配基线 | 本轮实现 |
|---|---|---|---|
| 资源部署 | 演示 Supabase + Vercel 代理 | 火山 BaaS / Pages / ECS 部署入口 | 保持该部署组合，补齐配置迁移与启动说明 |
| 视频执行 | 浏览器提交/轮询，部分模拟成功 | PostgreSQL 队列、Worker、租约、归档 | 创建任务绑定接口配置版本，更新配置不串供应商 |
| 视频计费 | 计费与实际任务脱节 | 创建预占、成功结算、确定失败逐笔返还 | 保持事务与幂等约束，配置不可用时扣费前拒绝 |
| 模型接口 | 前端密钥、硬编码网关、多处配置 | 主文本/视频已服务端化，旧函数仍各自配置 | 所有运行入口读取同一服务端模型配置 |
| 自定义图片 | localStorage 明文密钥、浏览器直连 | 仍保留旧弹窗及模拟渲染 | 设置页管理接口与密钥，服务器调用真实模型 |
| 配置管理 | 零散环境变量、工作台弹窗 | Secrets 模板，尚无统一设置 | 管理员设置页、加密密钥、版本记录、并发更新保护 |
| MCP | 独立调用供应商，计费旁路 | 用户 JWT 共用业务 API | 自动共用统一配置，不增加模型密钥 |
| 登录 | 短信模拟账号/固定密码 | Auth OTP、邮箱确认 | 保留；模型设置另加服务端管理员授权 |
| 封面 | 多条异步协议、随机 CTR，前后端字段不一致 | 遗留实现仍存在 | 真正图片接口、统一状态与字段，不生成虚假 CTR |

## 已确认遗漏

1. `glm-5-3-flash`、`deepseek-v4-pro`、`wenxin-text-generation`、`minimax-chat` 仍独立读取供应商环境变量，未共用主文本配置。
2. `stepaudio`、`siliconflow-audio` 的 endpoint/model/voice 分散在各函数中。
3. `src/lib/customModel.ts` 与工作台弹窗将 API Key 放进 localStorage；失败后工作台仍展示随机现成图片并提示生成成功。
4. 视频只保存 provider 名称，执行和查询都重新读当前环境配置。修改账号、网关或模型后，旧任务可能查错上游。
5. `CoverCandidates` 读取 `task_id`，数据库与服务端使用 `gen_task_id`；组件期望 `completed`，旧服务端返回 `SUCCESS`。旧封面接口还生成随机 CTR 分数。
6. 火山资源、模型权限、稳定域名和后台调度运行验收尚未完成；完成代码配置页不能作为已云端上线的证据。

## 实施约束

- 单一 `/settings/models` 页面，管理员管理平台接口。普通用户仅获得已启用模型的展示信息；服务端独立验证管理员身份。
- API Key 使用 AES-GCM 加密，主密钥 `MODEL_CONFIG_ENCRYPTION_KEY` 仅配置在 Edge Secrets。页面只显示“已保存”，不回传明文或密文，不在浏览器持久化密钥。
- 配置版本不可修改，当前配置记录指向版本。保存携带旧版本标识，拒绝并发覆盖；禁用只阻止新任务，旧视频继续使用原版本。
- 文本主备、同步图片接口（OpenAI Images / Chat Completions 图片 URL）、TTS、ASR、Reader、现有各视频协议统一配置 endpoint、query endpoint、model、认证方式、超时和必要选项。协议适配仍由服务端负责，不把不同协议伪装成同一接口。
- 设置接口允许导入既有服务端环境配置一次，运行链路不再静默回退环境变量或旧供应商。
- 保存与调用校验公网 HTTPS 地址，拒绝本机/内网/云元数据地址和重定向。上游错误只返回状态与可读原因，不回显密钥或原始响应。
- 主工作台图片改为真实服务端调用，失败明确报错；删除旧配置弹窗与 localStorage 密钥路径。封面统一使用图片服务和数据库状态。
- 旧文本/音频函数作为兼容入口使用统一处理器；部署清单同步更新，MCP 共用业务端点。
- 保留页面关闭后视频自动处理、任务幂等和逐笔退款回归。图片和提示词辅助的计费口径需明确记录，不将同步图片请求套成视频计费。

## 已落地结果

- 新增统一模型目录、服务端配置 API、13 个配置槽与 `/settings/models` 页面。文本主备、图片/封面、TTS/ASR、Reader 和七种视频协议共用配置；旧函数保留兼容入口。
- 密钥 AES-GCM 加密，Auth 管理员身份与数据库授权双重校验，API 不返回密文/明文；删除原工作台 localStorage 密钥与直连供应商代码，并清理旧浏览器存储键。
- 创建视频的同一事务绑定不可修改配置版本并复核启用状态；重复请求恢复原任务，禁用配置后旧任务仍可按原版本查询。配置保存并发冲突返回 409。
- 工作台图片与封面改为真实调用和 Storage 归档；失败明确报错，不使用随机图片。统一封面字段及状态，删除随机 CTR；历史未完成封面显示待核对。
- 增加公网 URL/DNS 校验、超时与禁用重定向，网络下载不携带模型凭据；连接检查仅调用保存的只读 GET 地址。
- 保存配置清理 LLM 缓存；模型任务 ID 去重按配置版本隔离，避免不同上游账号相同 ID 冲突。
- 新迁移、函数部署清单、Secrets 模板、管理员授权与迁移说明已同步。

## 仍需补齐及优先级

| 优先级 | 项目 | 当前事实与下一步 |
|---|---|---|
| 上线前 | 火山资源与账号 | 尚未完成有效 CLI 登录、BaaS/Pages/ECS 创建、模型权限及真实云端验收 |
| 上线前 | 业务收费 | 视频默认 10 积分；工作台同步图片与直接音频暂不收应用积分，仍产生供应商用量，需按成本确定收费 |
| 上线前 | 旧任务迁移 | 已受理旧视频必须核对原账号后绑定配置版本；未知受理仍走核对流程，不能凭配置变更退款 |
| 隐私需求上线前 | 私有素材 | Storage 仍公开，需私有桶、签名链接与用户授权播放 |
| 后续 | 同步图片恢复 | 图片已真实归档，但没有视频式持久化任务闭环；页面关闭、上游超时和重复生成需进一步任务化 |
| 后续 | 模型覆盖 | 新供应商协议需适配器；OpenAI 图片编辑/扩图/掩码、完整剪辑渲染未接入 |
| 后续 | 数据与发布 | 竞品与部分选品/数据页面仍为模拟分析，跨平台发布与数据回流未真实集成，不能作为运营数据 |
| 后续 | 运营与成本 | 缺运营后台核心源码、按模型定价及平台用量预算，需继续实现 |
| 网络治理 | 出口边界 | 已有 URL/DNS 校验仍存在解析到连接的时间窗，生产需可信供应商域名或出口策略 |

验证包含真实 PostgreSQL 资金/配置/任务事务、API 权限与密钥隔离、视频协议、图片真实归档及音频协议；生产构建、TypeScript、Biome 与 Deno 检查。设置页以真实组件和内存后端隔离验收保存、启用、检查连接及密钥输入清空，556px 视口未横向溢出；没有用页面验收伪造云端部署或调用真实收费模型。
