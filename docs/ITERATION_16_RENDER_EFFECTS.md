# 迭代16：真实画面效果与剪辑工程恢复

本轮沿用生产任务队列、私有素材和渲染Worker，新增真实像素效果。无需新增数据库迁移；仍须先发布00032–00044及匹配API，并重建FFmpeg镜像、最后更新前端。本地结果不能作为云端上线回执。渲染领取要求`render_version=2`，缺失/旧版本在领取租约前返回426，避免旧执行器忽略效果；分析预处理领取保持兼容。Worker探针增加render_version=2，通用version=6及required_migration=00044不变。

## 需求与产品范围

- REQ-RENDER-03：十二个转场标识可渲染，前端使用同一白名单；相邻主轨按开始时间排序，禁止含转场的主轨重叠，允许画中画叠加。默认交接0.5秒，工程协议可传0.02–2秒，实际不超过前后片段各自时长的一半，快速叠化最多0.15秒。
- REQ-RENDER-04：画中画支持正常、正片叠底、滤色、叠加、柔光、差值、色相、饱和度，保留定位、透明度、关键帧及区域外背景。
- REQ-RENDER-05：新增可调RGB色键，颜色、容差和边缘平滑在API及Worker分别校验。适用于绿幕/蓝幕/纯色背景；主体同色会被移除，不能称为人物语义分割、发丝抠像或自动训练。
- REQ-EDITOR-02：项目及本地草稿保存转场、混合、色键和滤镜强度；空工程保存清空结果。短工程保留精确时长，不强制补到30秒。数据库旧整数duration存上取整值，style_data.duration保存实际时长。

## 执行方案与接口

`render-effects.ts`统一前端与业务API的效果目录，`render_effects.py`提供固定像素公式，`render.py`执行参数二次校验、主轨顺序和真实合成。`production-jobs`仍以request_key事务创建render任务，不新增直连渲染旁路。

工程version仍为1，可新增`transitionDuration`；视频/图片元素可传`blendMode`（英文白名单）及`chromaKey: { color, similarity, smoothness }`。颜色为六位RGB，容差0.01–1、平滑0–1。错误类型/颜色/数值/蒙版/关键帧/主轨重叠在创建前拒绝。片段淡入淡出不可超过自身时长。

淡入淡出保留原行为；其他相邻转场以原片尾帧做过渡背景，不移动时间轴、不延长成片。新增左/右推入、闪白、圆形展开、像素溶解、横向展开、快速/闪动叠化、波纹与旋转擦除。旧标识保留，但原“光晕爆炸/立体翻转/鼓点识别”等名称改为实际像素效果。它们不执行BPM识别、三维变换或真实光学粒子模拟。

混合使用RGB分离公式或W3C SetSat/SetLum/ClipColor，按前景原始alpha做maskedmerge，避免把YUV色度替换当作CSS色相混合。RGB调色替换会丢alpha的eq，保留色键及旋转透明蒙版。浏览器仍主要预览原片段；色键及转场明确标为导出后生效，混合预览映射完整CSS模式，最终以MP4为准。

## 演示逻辑清理

新工程无默认视频/配乐/字幕；素材空态不回退预置视频，加载时不再给特定邮件账号写入演示作品，缺失成片URL不替换公开示例。用户素材不按名字隐藏，加载草稿不删除用户轨道。语音识别为空或失败明确提示，不写固定带货字幕。脚本与识别入口连接现有工作台；三秒切分明确为手动剪辑辅助，保留sourceStart及speed，带关键帧/淡变的片段使用原播放头切分。

原资源商城、部分音效/贴纸演示和完整自动编排仍需后续处理；本轮清理范围不证明整个编辑器已经没有遗留演示。人物语义分割、真实鼓点检测、多镜头自动编排和其他原始专业效果仍为缺口。

## 验证与发布

AT-RENDER-03–06：实际FFmpeg共12项测试，包含原裁剪/拼接/音频/字幕/4:5/滤镜/取消/超时，以及十种新增转场逐帧检测、七种非正常混合、W3C RGB参考数值、画中画空间/时间边界、色键前景和透明度。本地完整执行96.044秒通过。三组API协议验证十二转场、八混合、计费前非法参数拒绝及Worker旧版本领取前拒绝；既有production六组与analysis四组回归通过。

工程检查包括TypeScript、Biome、实际ast-grep规则、Deno production-jobs/production-worker检查和构建。浏览器独立验证效果参数/私有稳定URL/2秒工程及保存刷新恢复，并检查390px弹窗，截图已检查；重开色键参数与明确关闭按钮一起验证。执行结果记录在本轮提交及测试报告。浏览器使用隔离API替身，媒体像素以独立真实FFmpeg测试为证，不连接生产模型或用户素材。Docker镜像已重建，新增模块进入实际镜像。

生产上线须对真实不同编码/透明图片/抠像素材、4K与长工程资源开销、移动预览和真实租约取消做验收。色键边缘有压缩噪声，用户须检查成片；HSL逐像素公式成本较高，应按实际素材压测，不能将短测试视为容量SLA。更新Worker镜像必须包含新增render_effects.py，旧Worker会拒绝新增效果或忽略其参数，禁止只发前端。
