# 迭代31：账号隔离、个人中心与分镜入口

日期：2026-10-22。本轮新增00059，production预检升级probe19/required_migration=00059，渲染协议保持render4/edit2，MCP仍59工具/19业务权限。源码与隔离验证不表示目标环境已发布。

## 实际行为

- Auth资料读取以当前身份和请求代次核对结果，切换立即清除旧资料；初始会话读取不能覆盖后来的认证事件。SDK认证回调只更新状态，资料读取在下一轮事件循环执行，避免等待SDK自身锁。
- 资料读取故障和缺档案明确报错并可重试，不由浏览器自动创建profiles、补邀请码或代做注册赠分事务。注销失败保留错误提示，迟到结果不清除后来登录的新账号。
- 账号重建整个业务布局与独立React Query缓存，同时过滤继承的路由输入，防止旧账号脚本和商品信息预填到新账号。已有逐项上传/任务身份核对继续保留；这不代表所有历史异步写入或目标身份审计均已验收。
- 个人中心使用本人数据库聚合，不受Data API默认1000条响应上限影响。视频项目、实际完成成片与平台published记录分别计数；近30天按用户时区与项目created_at统计，包含零天。失败显示未知或上次成功数据，不用零值代替错误。
- 头像可使用姓名缩写，或上传自有JPG/PNG/WebP；校验实际解码、尺寸和2MB限制，确认使用权后复用原素材登记。头像入库后资料保存失败，在当前页保留登记引用，重试不再次上传。profiles新增媒体引用触发器与存量回填，引用未移除时不能删除原素材。
- 通知偏好检查实际更新返回值，失败不切换状态或提示成功；密码修改核对当前会话和返回用户，账号安全展示当前会话的邮箱/确认/最近登录，并提供退出所有会话。历史登录设备列表尚需身份服务审计。
- 首页“分镜编辑”原入口继续存在，复用ScriptPage、WorksPage和BatchCreatePage，提供商品与手动剪辑入口。移除旧向导重复上传、随机匹配置信度、AI失败后模板成功以及停用的生成末步。旧商品草稿按原账号保留，可将商品/卖点继续传入脚本页；不改写历史数据库记录。
- 脚本流直接消费共享SSE工具已解码的正文，校验分镜与完整Prompt后更新结果；非法/中断/失败保留原输入和已有结果，离页中止请求。结构状态来自实际返回的layer标注，不再用定时动画冒充独立模型步骤。
- 脚本与知识保存先持久原UUID，未知响应后查原记录并核对内容，再恢复原内容；刷新后提供“恢复原脚本保存”入口，已确认内容复用保存记录。回执按账号保存，保留最多20份待确认及最近20份确认内容；缺失已确认记录不自动恢复已删内容。
- 确认后的2–6分镜可进入现有后台多镜头工作台，携带镜头Prompt和台词。用户选择对应商品、填写音色，确认统一镜头时长和预算后才创建任务；不会自动宣称成片或发布成功。
- 压缩回归发现快速跳转会取消500ms草稿防抖队列，修复共享useDraft为离页/刷新/换键时保存最后一次内容到保存时的原键。脚本完整分镜与Prompt也保存在本人草稿，切换账号不会写入另一人的键。
