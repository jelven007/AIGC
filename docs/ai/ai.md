## 2. 任务与配置

视频创建在同一数据库事务检查启用状态、扣费、绑定不可变配置版本。提交/查询按原版本，成功先转存再结算；明确失败关联原流水返还积分。POST 超时/5xx/无 ID 保留待核对，不能认为未受理或自动换供应商重提。

文本仍为同步调用；图片和五类媒体任务均已后台化，归档复用原证据，响应失联恢复原UUID，未知受理保留预占。旧同步音频接口410，浏览器朗读不作为模型成功结果。当前云端仍缺最新增量，不能据源码推断已启用。

## 3. 提示词设计规范

提示词输入分开记录商品事实、受众、语言、平台、长度、素材和限制。结构化输出用可校验 schema；服务端验证字段/类型/长度，模型输出不是可信数据库状态或资金证据。

| 任务 | 输入策略 | 输出与人工判定 |
| --- | --- | --- |
| 卖点提取 | 只使用授权描述/页面事实，区分事实与创意建议 | 卖点/适用人群/缺信息；不虚构功效、销量、认证 |
| 脚本/分镜 | 钩子、问题、商品展示、行动建议；指定语言/时长 | 镜头/台词/时长/画面说明，检查总时长与可拍性 |
| 翻译 | 保留商品名、数量、分镜与占位符，指定地域语气 | 人工检查事实和自然度，不承诺小语种“完美” |
| 视频 | 明确主体、材质、场景、动作、镜头、光线和参考素材 | 检查商品形态、运动、规格；不靠模型生成可验证销量 |
| 图片/封面 | 商品主体/背景/布局与已授权参考图 | 看外观一致性/可用性；不生成 CTR 预测分数 |
| 音频 | 清晰文本与读音，支持的模型/音色 | 商品名/数字/语言、可懂度、真实可播放 |

上述为开发/评估规范，不表示所有既有 Prompt 已完成重构。商品网页与模型输出作为外部数据，不授予工具执行/管理员权限；日志不保存 Key/JWT 或不必要的完整素材。

## 4. 评估与成本

固定商品样本、输入、供应商/配置版本、规格和评价标准；记录所有尝试、失败/unknown、人工接受原因、总费用与耗时。质量数据不得取自随机 CTR、模拟选品/竞品或虚构业务指标。

视频默认10应用积分，图片/封面各10，TTS/ASR各2，即时克隆/照片口播/口型各10；媒体提交确认真实价格，共用10个未结案任务上限。ai-assistant Action按表计费，文本辅助暂不收积分。供应商用量与应用积分分开，退款积分不表示供应商退款。

测试见[TEST_PLAN](../testing/TEST_PLAN.md)，本轮证据见[实施台账](../archive/reviews/OPTIMIZATION_IMPLEMENTATION_20261027.md)。32例版本化评估分别记录结构/人工事实/真实成本，主备逐次attempt与unknown不混入成功；真实开通、质量和供应商账单仍需实测。
