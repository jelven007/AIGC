# 产品演示视频脚本模板

更新：2026-10-21。用于制作项目说明视频，沿用文件名以兼容旧链接；不表示已生成或已发布宣传片。

## 内容脚本

| 片段 | 画面 | 旁白要点 |
| --- | --- | --- |
| 商品准备 | 真实授权商品/素材页面 | 准备商品事实与素材，选择已启用模型 |
| 模型与任务 | 隐藏密钥的目录/实际任务状态 | 配置服务端管理；视频提交可离开页面 |
| 任务结果 | 实际可播放作品与脱敏流水 | 成功归档结算；明确失败返还应用积分 |
| 当前边界 | 当前状态与验证范围 | 官方后端仍待升级，火山是可选方案；未交付能力标规划 |
| 后续工作 | 需求/测试/运行文档入口 | 按真实验收、质量和成本推进试点 |

素材没有完成实测时使用架构/源码/测试说明，不拼接第三方生成视频冒充自己的任务。任务 unknown 应写“受理待核对”，不能演成失败自动现金退款。

## 后期与授权

字幕/标识由后期排版，避免生成模型输出精确文字。配音选配置供应商已开通且授权的音色，不承诺自动口型同步；音频与视频拼接/渲染能力必须独立验收。画面不含 Key/JWT/支付私钥或个人推广二维码。

取真实任务时记录授权来源、job/config版本、日期和人工处理；预览/测试素材不得当商家转化案例。最终用 [演示提纲](../ppt/ppt.md)、[当前状态](../CURRENT_STATE.md) 与 [验证报告](../TEST_REPORT_20261021.md) 校稿。
