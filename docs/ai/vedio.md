# 产品演示视频脚本模板

更新：2026-10-22，功能基线d7e3d38。用于说明视频，沿用旧文件名兼容链接，不表示已生成/发布宣传片；范围见 [发布基线](../archive/reviews/RELEASE_BASELINE_20261022.md)。

## 内容脚本

| 片段 | 画面 | 旁白要点 |
| --- | --- | --- |
| 商品准备 | 真实授权商品/素材页面 | 准备商品事实与素材，选择已启用模型 |
| 模型与任务 | 隐藏密钥的目录/实际任务状态 | 配置服务端管理；视频提交可离开页面 |
| 任务结果 | 实际可播放作品与脱敏流水 | 成功归档结算；明确失败返还应用积分 |
| 当前边界 | 当前状态与验证范围 | 官方后端仍待升级，火山是可选方案；未交付能力标规划 |
| 后续工作 | 需求/测试/运行文档入口 | 按真实验收、质量和成本推进试点 |

素材没有完成实测时使用架构/源码/测试说明，不拼接第三方生成视频冒充自己的任务。任务 unknown 应写“受理待核对”，不能演成失败自动现金退款。

## 后期与授权

字幕/标识由后期排版。配音选实际开通/授权音色；后台口型和多镜头配音字幕合成已有本地协议/FFmpeg证据，实际口型/人物/语言质量需独立验收。发布要真实成片预览/逐账号确认，画面不含凭据或个人信息。

取真实任务记录授权来源/job/config版本/日期/人工处理，测试素材不作商家转化案例。最终依 [演示提纲](../ppt/ppt.md)、[当前状态](../CURRENT_STATE.md)与 [最新报告](../archive/reviews/TEST_REPORT_20261022.md)校稿。
