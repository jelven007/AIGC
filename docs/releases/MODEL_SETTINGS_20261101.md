# 模型接口页面更新记录

类型：reference。读者：开发、测试和发布维护者。责任：仓库维护者。日期：2026-11-01。源码为v1.2.1；环境晋级结果以当轮回执和[当前状态](../CURRENT_STATE.md)为准。

本次按11项要求更新说明、入口名称和分类顺序。模型页移除独立密钥说明、退役说明、备用文本模型、MiniMax视频和Seedance网关入口。文本/向量入口名称为“主模型”；视频Seedance2.5/Seedance2.0mini，图片Seedream5.0flash，音频声音复刻，数字人照片口播/视频口型。显示名调整保留原供应商协议、实际模型ID与历史密钥。

“新建模型配置”支持文本、视频、图片、音频、3D、向量。管理员填写类型和名称后，由00069 RPC建立默认关闭的配置，入口追加到对应分类。3D分类在有配置时出现。配置、版本和密钥复用原服务端机制；创建UUID允许失败重试，并发同请求只产生一项。普通用户只读目录，不能管理接口。

内部20个服务槽和不可变旧版本保留；显式模型页提供13个内置入口及自建项，第三方集成仍为4个槽。无scope的业务目录兼容原固定路由。自建项目前提供配置管理，不自动替换业务默认槽或增加3D生成任务。

验收范围包含真实表单六类创建/保存/刷新、手机弹窗尺寸、创建失败重试、加载恢复和集成边界，Node模型/密钥回归，真实PostgreSQL并发/版本/权限，lint/typecheck/build。执行任务契约继续为00068/probe24/render4/edit2，完整部署为69迁移文件、67生产迁移和43生产Edge。

环境升级使用同一冻结源码、前端与Edge产物，保留各架构执行镜像和原业务数据。v1.2.1-4ad1f6a30142已在开发5173、本地HTTPS8443与ECS运行，源码SHA256为4ad1f6a30142b385c5b60f94aff5c3d5650090d006b5e2fd5cbd271c8903c7b3。构建记录worktree_changes=true；git_sha仅为工作树基础提交，不代表精确提交构建。

三个环境各1440px/390px页面通过分类与文案、13个入口切换、新建弹窗六类选择/填写/取消、刷新与重载检查，共78次内置配置切换。没有横向溢出、框架错误覆盖层、页面异常或失败响应。浏览器插件工具不可用，使用已有Playwright与Chrome；本地/ECS通过回环代理访问，HTTPS上游严格校验CA与主机名。

两部署分别核验555个冻结源码文件、199个前端文件和44个Edge文件（含清单），页面模块HTTP字节摘要与冻结载荷一致；runtime-config按各实例原地址与公开配置单独核验。生产账本67条、最新00069，服务角色可执行新建RPC、普通用户无执行权。模型目录13项、集成4项、原业务目录20项，未登录与无效创建请求被拒绝；目录不返回密钥。

本地和ECS数据库分别在BEGIN/ROLLBACK事务内验证六类创建、保存、幂等重试与旧版本保留，未留下验收配置。实际线上成功创建/保存API未直接持久化测试项；该流程的界面覆盖来自六类浏览器夹具测试，数据库覆盖来自独立真实PostgreSQL与部署事务验证。未进行真实付费供应商调用。
