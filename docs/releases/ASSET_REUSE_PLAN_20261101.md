# 旧素材复用实施计划

**目标：**按用户要求复用35个旧图片和6个宣传组件，功能名统一为「爆款风格复刻」。

**架构：**原件保持归档；公开目录只包含经过裁剪和压缩的WebP衍生图。每个衍生图记录原件摘要、裁剪坐标、用途和提示词。介绍页复用六个组件并新增视觉参考图库，参考提示词通过已知素材编号带入工作台。

**技术：**React、TypeScript、现有Tailwind主题、Radix Dialog、FFmpeg、Playwright。

用户已要求执行复用。本轮在当前工作区内实施，不创建提交；执行范围沿用当前介绍页、工作台与登录入口。

1. 在 `tests/browser_asset_reuse.mjs` 建立筛选、预览、复制、登录恢复和移动宽度回归，先核实当前图库缺失。
2. `scripts/prepare_inspiration_assets.py` 按35项映射校验归档摘要，裁剪旧文字/品牌/指标，输出 `apps/web/public/inspiration/` 和 `apps/web/src/lib/inspirationAssets.json`；原件不写入、不改动。
3. 重构 `HeroSection`（首屏及人物拼图）、`HowItWorksSection`（真实创作步骤及界面构图）、`StatsSection`（参考数量与访问保障）、`TestimonialSection`（三种用户场景）、`PricingSection`（真实套餐入口）、`ContactSection`（FAQ与现有工单入口），全部接入 `LandingPage`。`LandingHero` 保持调用兼容并委托首屏组件。
4. 新建 `InspirationGallery`，提供五类筛选、大图预览、可选/可复制提示词及创作入口；全部35图可访问。提示词入口只选择文字，生成须用户另行确认。登录页仅接受明确站内去向；工作台按公开编号读取提示词。
5. 来源门禁继续拒绝旧演示目录，另校验复用图摘要及目录完整性；阻止未经登记的素材混入候选构建。
6. 更新清理历史的后续状态、逐图复用清单、PRD、开发与运营说明、文档生命周期和待发布状态。
7. 执行来源检查、完整lint/build、受影响回归和真实浏览器操作；检查35图加载、桌面/手机/横屏尺寸、预览关闭及登录去向。分别记录开发、本地构建和线上状态。

验收：35/35素材有用途和衍生图、6/6组件接入、旧功能名零残留；所有新入口可操作，图库没有被当作实际作品、客户见证或真实指标。线上未晋级时只报告已核验的本地结果。

执行结果：以上七项工作区实施与验证已完成。最终逐图映射、39项Node与多环境浏览器证据见 [复用验收记录](ASSET_REUSE_20261101.md)。本次未发布到本地自托管或线上ECS。
