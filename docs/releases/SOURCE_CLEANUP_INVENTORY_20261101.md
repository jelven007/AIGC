## 六个宣传组件

原位置均为 `apps/web/src/components/`。旧 `pages/marketing/Index.tsx` 曾引用这些组件；当前路由使用现行 `LandingPage`，旧Index现只转到现行介绍页。以下记录初次清理原因；当前六个组件已按现行业务重构并由 `LandingPage` 调用。

| 文件 | 旧页面作用 | 清理原因/实际内容 |
| --- | --- | --- |
| `HeroSection.tsx` | 旧首页首屏/主宣传区 | 旧宣传布局、动画与CTA，已由现行 `LandingHero`/`LandingPage`承接 |
| `HowItWorksSection.tsx` | 旧三步使用流程 | “提供想法→AI生成脚本→定制”，包含“几秒钟”“最大化互动效果”等无本轮证据口径 |
| `StatsSection.tsx` | 宣传数据卡片 | 硬编码“节省90%时间”“观看时长3.2倍”“10K+创作者”，不是实际经营统计 |
| `TestimonialSection.tsx` | 客户评价区 | 三个固定姓名/评价及“观看时长+38%”“300万+观看”“粉丝+64%”，没有对应客户验证记录 |
| `PricingSection.tsx` | 旧套餐价格展示 | 硬编码免费版、69元专业版、139元高级版、无限脚本/7天试用/年付优惠，与当前服务端套餐及订单权益脱节 |
| `ContactSection.tsx` | 联系方式和留言表单 | 占位邮箱/电话/地址；提交仅触发“消息已发送”toast，没有实际发送接口 |
