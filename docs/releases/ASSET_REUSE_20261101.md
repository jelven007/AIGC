## 六个组件

| 组件 | 当前职责 | 复用调整 |
| --- | --- | --- |
| `HeroSection` | 首屏、创作入口、三图人物拼图 | 沿用主宣传结构，使用现行文字/主题与参考图片；`LandingHero`委托此组件 |
| `HowItWorksSection` | 四步创作流程 | 保留编号步骤与视觉示意，去掉“几秒”“保证效果”等承诺 |
| `StatsSection` | 参考数量、类别和账号管理 | 数量从目录计算，以35个参考/5类方向替代旧经营指标 |
| `TestimonialSection` | 个人、商品品牌团队、内容机构三种场景 | 保留三栏人物/内容结构，改为使用场景和六图拼图 |
| `PricingSection` | 套餐目录、积分和记录入口 | 进入真实套餐页面，显示现行权益；退出硬编码价格/折扣/试用 |
| `ContactSection` | FAQ和支持工单入口 | 可展开FAQ；登录后进入现有支持中心 |

不是简单恢复原文件或添加空包装。六个组件分别渲染其内容，均由现行介绍页调用；新增 `InspirationGallery` 管理35张图的筛选和预览。

## 交互与边界

点击参考图打开Radix预览，支持Escape与关闭按钮；关闭后焦点回到原图片按钮。提示词可选中、复制，复制失败显示手动复制说明。

创作入口使用 `/video/create?inspiration=ref-NN`，登录前只携带公开编号，登录后恢复相同思路。工作台只预填文字，用户继续修改、选择自己的素材、模型和规格，再确认任务。选择参考不上传图片、不创建数字人、不提交生成，也不改变积分、商品、任务或订单。登录恢复只接受明确的站内套餐、支持及有效参考编号。

视觉参考与实际作品保持独立：图库不注入用户作品库、商品库或数字人库；静态示意不是当前工具截图、模型输出质量证明、真实客户评价或增长数据。正式创作和商业使用的素材继续由创作者确认用途与使用权。


重新生成衍生图时从源码外只读归档运行：

```sh
docker run --rm --entrypoint python \
  -v "<归档绝对路径>:/archive:ro" -v "$PWD:/workspace" -w /workspace \
  aigc-render-worker:local scripts/prepare_inspiration_assets.py \
  --archive /archive --root /workspace
```

生成器先核对35项原件摘要再裁剪输出；更新输出后必须重新核验图片内容、执行来源门禁和浏览器回归。
