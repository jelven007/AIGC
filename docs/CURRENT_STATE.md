## 运行约束

1. 应用积分与供应商现金用量分开核算。批次固定整批预算和逐阶段原流水；确定失败及未启动取消返还，已受理和未知提交不按超时盲退。
2. 模型配置在创建事务绑定不可变版本，启停和换密钥只影响新任务。密钥目录按原key_id/用途读取，轮换前预检全部历史凭据并备份完整目录，不能覆盖或删除旧键。
3. 供应商POST未知时保留原UUID与证据核对；查询和存储暂时错误恢复，不重发已受理任务。健康检查通过不等于真实模型或平台成功。
4. 多镜头台词由用户确认，完整配音超出镜头总时长明确失败；字幕来自实际时间戳。公开发布需实际成片预览和逐账号确认。
5. 官方托管和火山托管使用不同资源及迁移回执。不能用火山发布脚本重放无其回执的官方旧库。
