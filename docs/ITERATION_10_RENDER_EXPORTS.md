# 多规格导出与供应商生命周期

日期：2026-10-21。增量迁移 `00039_render_exports.sql`，配套 `production-jobs`、导出页与 FFmpeg Worker；本地验证与实际云端部署分开记录。

## 交付行为

- `/export-formats` 支持六种画幅（9:16、16:9、1:1、4:3、3:4、4:5）与三档短边（720、1080、2160），最多18种组合。输出为 MP4 H.264/AAC，等比缩放补黑边，不裁掉商品内容。
- 服务端读取用户自己的已完成源作品、校验素材权限。一个事务创建导出记录、全部输出作品和独立渲染子任务；任意一项失败回滚全部新增，前端不先创建占位作品。
- 用户账户锁串行协调创建，每人最多24个未结案渲染任务；普通剪辑入口和多规格入口共用上限。容量不足返回429；既有请求恢复不受容量或源作品删除影响。
- 浏览器提交前保存原UUID和全部规格。503/失联保留回执，刷新后用户恢复原请求；同键不同参数409。旧版单规格回执仍可查询/恢复原任务，历史单规格记录在任务中心查看。
- 每种规格独立渲染和归档，部分失败不会隐藏其他成功成片。导出页按子任务实时汇总进度/完成数，成功项有独立下载与发布入口；详情不回传租约/原始素材/模型证据。
- 4:5同时进入 API 和 Worker 校验。八种滤镜按预览采用的RGB变换和强度执行，轨道滤镜优先于全局滤镜；0%保持原画。实际编码与浏览器色彩空间仍需素材验收，特殊转场、抠像、非正常PIP混合继续明确拒绝，未冒称已交付。

## 接口

`production-jobs` 保持 POST 与函数内 JWT/API Key 鉴权：

| Action | 权限 | 参数 / 返回 |
| --- | --- | --- |
| export | render:create | request_key、source_project_id、formats[{ratio,height}]；202 {export} |
| query-export | jobs:read | export_id或request_key；{export}，无本人记录404 |
| exports | jobs:read | 最近20个导出批次；{exports} |

客户端不提交user_id、源URL或源时长；服务端读取并在数据库事务内核对源URL版本，避免读取后被修改。格式按固定次序归一化，选择次序变化不产生新请求。导出子任务复用既有 `production_jobs`/领取租约/归档事务，不另建模型执行器。

数据库 `render_exports` 仅service_role可读写，关联 `production_jobs.export_id`；`create_render_export` 和队列配额包装仅service_role可调用。原 `create_production_job` 签名保持，内部旧函数撤销所有直接执行授权。

## Sora退役事实

2026-10-21核对 [OpenAI官方API文档](https://developers.openai.com/api/reference/resources/videos/methods/create) 与 [退役通知](https://help.openai.com/en/articles/20001152-what-to-know-about-the-sora-discontinuation)：Sora 2模型及Videos API已于2026-09-24关闭，无一对一替代接口。不能把历史文档作为当前可用服务恢复。

`RETIRED_MODELS` 在设置页提供退役日期/官方链接，独立于13个可配置槽，不能启用或创建计费任务。原Sora旁路维持410，官网改为现有视频供应商。未来任何仍可用的第三方兼容服务必须另行确认服务、协议、账单和权限，不能冒称官方Sora仍可用。

## 启用与运营

1. 核对目标已部署回执，应用缺失00032–00039。不向当前官方旧库全量重放迁移，不以火山工具替代官方管理协议。
2. 部署匹配的production-jobs和共享模块，更新并重建FFmpeg镜像，配置既有production调度，最后发布前端。
3. 验收私有源素材、六画幅、关页恢复、并发/队列容量、部分故障、单项下载播放与发布。实际供应商/平台/云端未因本地测试而成为已验收。
4. 当前render不扣应用积分；渲染/存储/带宽有真实成本，队列容量不是费用预算。运营记录每次导出规格/资源耗用并据实际负载设限。
5. 监控最老pending/running、租约、未知、FFmpeg失败和Storage归档；重试原任务，不能把父记录直接改为成功。长期任务与备份恢复/自动告警仍需目标环境建设。
