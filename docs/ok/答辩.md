## 🏬 维度一：商业模式与痛点匹配

### Q1：市面上已经有剪映、Runway、HeyGen 等强大视频工具，Shopro AI 的核心竞争力和护城河是什么？为什么电商商家要选你们？

**答辩参考回答（真实亲切）：**
> “谢谢评委老师的提问。您提到的剪映、Runway 和 HeyGen 都是非常优秀的产品，我们在开发过程中也经常学习它们。但我们在深入调研电商商家后发现，**通用视频工具与电商带货场景之间存在较深的断层**：
> 
> 1. **定位不同**：剪映偏向手动剪辑，HeyGen 偏向企业宣讲和单人说话，成本昂贵且缺乏‘电商销售基因’。
> 2. **Shopro AI 的核心痛点切入**：商家要的不仅仅是‘做个视频’，而是‘高转化、低成本量产爆款’。我们做的是**电商全流程营销 SaaS**：
>    - **商品 URL 极速解析**：粘贴商品链接，AI 自动提取 3 大核心卖点。
>    - **CoT 4层营销脚本**：基于‘钩子-痛点-产品-行动召唤’思维链生成文案，而不是毫无逻辑的通用介绍。
>    - **多轨道可视化轻量剪辑 + 一键跨平台发布**：直接打通抖音、TikTok、快手等平台。
>    - **ROI 数据回流闭环**：通过广告与播放数据回流，反哺 AI 重新优化低分脚本。
> 
> 总结来说，我们的护城河在于**‘深度绑定电商营销全链路 workflow’**。通用工具是给剪辑师用的，而 Shopro AI 是给电商老板和运营人员用的——‘一人 + 浏览器’就能完成过去 5 人团队的带货视频量产。”

### Q2：商家用你们系统生成的视频，同质化会不会严重？怎么保证视频在平台上的推流转化率？

**答辩参考回答（真实亲切）：**
> “老师这个问题非常切中电商命脉。AI 生成最怕的就是‘千篇一律’导致平台判定重度重复。我们在产品设计上从三个层面解决这个问题：
> 
> 1. **分镜与 Prompt 动态组合**：每次生成脚本时，DeepSeek-V4 会结合商品独特的卖点与目标受众生成不同的 CoT 逻辑，配合 Seedance 2.0 / Kling / Luma 等多模型视觉生成，避免固定模板死板渲染。
> 2. **NLP 情绪对齐与配音丰富度**：系统利用 NLP 分析台词的情感极值，将情绪标注在时间轴上，并匹配 CosyVoice2 的多语种语气（平和、激昂、担忧、说服等），让数字人口播具备情绪张力。
> 3. **内置 A/B 测试与流量预测**：系统内置了流量完播率预测模型，并支持一键生成 A/B 变体脚本。商家可以同时发布多套封面和文案版本，在线追踪完播率与点击率，快速淘汰低效版本。
> 
> 当然，我们也客观地向商家建议，AI 提供的是 80% 的高效率基底，配合我们可视化编辑器进行 20% 的微调，效果是最好的。”

## 💻 维度二：技术架构与 AI 落地

### Q3：系统调用了 DeepSeek、CosyVoice2、Seedance 2.0 等多个大模型，在技术架构上你们是如何组织和调度的？遇到 API 超时或失败怎么处理？

**答辩参考回答（真实亲切）：**
> “在技术架构方面，我们没有把所有逻辑塞在前端，也没有构建沉重的单体后端，而是采用了 **Supabase Edge Functions (Deno 运行时) + 统一微服务网关** 的轻量弹性架构：
> 
> 1. **统一 AI 网关 (`ai-assistant`)**：所有前端 AI 请求通过 `ai-assistant` 进行路由分发，实现了业务解耦与统一鉴权。
> 2. **异步队列与流式响应 (SSE)**：
>    - 文本生成使用 SSE 打字机流式输出，确保用户在 1 秒内看到文案生成，极大降低等待焦虑。
>    - 视频生成（如 Seedance 2.0 / 可灵）由于耗时较长（10~30秒），我们采用了**‘任务提交 (`submit`) ➔ 数据库登记异步状态 ➔ 轮询/回调 (`query`)’**的机制，防止 HTTP 连接长时间超时。
> 3. **模型冗余降级 (Fallback) 机制**：如果 DeepSeek 接口遇到高并发超时，边缘函数会自动切到备用模型（如文心一言代理）；视频接口若 Seedance 繁忙，系统支持切到可灵或 Sora 接口。
> 4. **失败重试与任务监控**：我们设计了专门的 `TaskQueuePage` (任务队列监控页)，记录每个 API 调用的日志与状态代码，支持商家一键重试失败的任务，避免重复扣费。”

### Q4：多语言翻译和出海配音（TikTok / Shopee）目前的效果如何？如何保证海外小语种的本地化地道程度？

**答辩参考回答（真实亲切）：**
> “对于跨境出海商家，语言本地化确实是个大痛点。我们在系统里集成了 **DeepSeek 营销多语种翻译 + CosyVoice2 情感配音引擎**，目前覆盖了英语、印尼语、越南语、泰语、西班牙语等 16 国主流市场：
> 
> 1. **翻译不只是直译**：我们在 Prompt 里加入了跨文化营销语境约束（例如东南亚电商偏好的高互动性、欧美市场偏好的简练诉求），翻译时保留原脚本的 CoT 营销架构。
> 2. **语音情感合成**：采用 CosyVoice2-0.5B，能根据台词的情绪标记自动调整语调和语速，避免过去机械翻译配音的‘翻译腔’。
> 3. **16 国真实选品矩阵**：我们预置了 16 个国家的本地化选品素材与实物图片，方便商家快速套用。
> 
> **实事求是地说**：文化壁垒非常复杂，AI 目前能帮商家完成 85% 以上的地道表达，极少数带有当地俚语或特定节日梗的内容，商家可以通过我们的字幕轨道进行手动替换。”

## 🔒 维度四：数据安全、并发与合规

### Q7：如果平台高并发下有大量用户同时提现或生成视频，甚至有黑客恶意并发调用接口‘薅算力’，你们系统在安全和并发上是怎么设计的？

**答辩参考回答（真实亲切）：**
> “这个问题非常专业。在设计 SaaS 计费系统时，算力安全与并发控制是我们的重中之重。我们在数据库与微服务层设计了三重防护：
> 
> 1. **PostgreSQL 悲观锁 (`SELECT ... FOR UPDATE`)**：
>    - 在积分扣减的数据库存储过程（RPC）中，我们采用了 `SELECT ... FOR UPDATE` 悲观锁机制。任何积分消费请求在扣减时都会锁定当前用户行，**在物理层面杜绝了并发超扣和恶意薅算力的漏洞**。
> 2. **行级安全策略 (RLS - Row Level Security)**：
>    - 数据库全程开启 Supabase RLS 策略，隔离不同租户和团队的数据。用户 A 绝不可能通过修改前端 ID 查到用户 B 的商品、脚本或作品资源。
> 3. **AI 内容安全审核与接口限流**：
>    - 边缘函数内置了 `content_moderation` 模块，对生成的敏感营销词汇进行实时拦截。开放平台 API（OpenAPI）支持 `ak_...` 密钥管理与实时撤销（Revoke），保障接口安全。”

## 💰 维度五：成本控制与盈利测算

### Q8：生成一条短视频的真实 API 算力成本大概是多少？你们的盈利空间有多大？

**答辩参考回答（真实亲切）：**
> “我们对每一项 API 调用都做了精细化的成本核算与优化，数据非常透明真实：
> 
> 1. **单条视频的 API 原生成本测算**：
>    - **文本解析与脚本生成（DeepSeek-V4-Flash）**：约 0.005 ~ 0.01 元 / 次。
>    - **情感语音合成（CosyVoice2-0.5B）**：约 0.03 ~ 0.05 元 / 条。
>    - **短视频渲染（Seedance 2.0 720P 5秒）**：约 0.30 ~ 0.50 元 / 条。
>    - **综合单条视频算力成本**：控制在 **0.4 元 ~ 0.6 元人民币** 左右。
> 2. **对比传统制作成本**：
>    - 传统拍一套带货短视频（含剪辑师+外籍主播口播+拍摄）：单条成本在 100元 ~ 300元 左右。
>    - 使用 Shopro AI 降本幅度超过 **98%**。
> 3. **商业定价与毛利空间**：
>    - 我们的充值积分套餐换算下来，商家生成一条视频消耗约 1.5 ~ 2.0 元的积分。
>    - 在扣除 API 成本、云服务器与存储成本后，**系统的毛利润率保持在 55% ~ 65% 之间**，具备良好的现金流健康度。”
