# 项目说明与常见问题

更新：2026-10-21。用于真实介绍产品与评审，不使用旧无证据的答辩话术、成绩或商业承诺。

## 当前依赖与部署

系统仍依赖 Supabase Auth/PostgreSQL/Storage/Edge Functions，当前实际官方 Supabase。火山 BaaS/Pages/ECS/方舟已有适配与发布工具，未完成资源/模型验收；不是已经迁离官方。云端到00031与旧三函数，最新00032–00034还需配套发布。

## 产品完成度

代码已完成服务端视频任务、幂等资金、管理员配置版本、真实同步图片/音频与 MCP API 收敛。当前正式生产闭环尚需云端/供应商/支付/运行验收；批量、完整渲染、真实投放与数据回流、运营后台不可因为页面存在而称交付。新私有媒体/生产任务开发见 [待验收记录](../PENDING_CHANGES.md)。

## 任务故障与积分

创建预占，成功先转存再结算，明确失败按原流水返还应用积分。POST超时/5xx/无ID保留核对，不能盲目重提或按超时退款。旧任务绑定不可变配置版本，换账号不改变它查询的供应商。现金退款遗留接口未完成原子资金/权益闭环。

## 模型、素材和安全

模型Key在服务端AES-GCM密文版本，管理员Auth身份与数据库独立校验，客户端无模型Key。13槽代表协议目录，真实模型与权限由目标账号确认。当前基线Storage公开，不承诺私有素材；RLS/ACL测试不等于完整安全或负载审计。

## 成本和用户价值

注册默认20积分，视频默认10；这是应用默认配置，不是现金兑换/上游报价。同步工作台文本/图片/音频暂不收应用积分，但平台承担供应商用量。真实成本、制作时间、质量/留存/转化需试点测量，没有验证结果不填数字。

## 测试证据

本轮76个具名用例与14个测试组，TypeScript、6关键Deno函数、生产构建通过。只读云端核对和此前真实邮箱/无模型失败退款另有记录；真实供应商生成、支付沙箱、公网MCP、负载与恢复演练仍待执行。
