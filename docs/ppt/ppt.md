## Slide 2: 一、需求洞察 🔍 | 痛点与解决方案

### ❌ 传统视频制作痛点
*   **成本高昂**：雇用外籍演员与搭建专业录音棚成本极高（单条视频高达 ¥500 - ¥2000）。
*   **效率低下**：常规策划、拍摄、配音及剪辑通常耗时 2-3 天，完全跟不上短视频平台流量热点变化。
*   **转化平庸**：传统文案缺乏针对性的营销钩子，完播率低，商品卖点难以吸引受众。
*   **多语种门槛**：跨境出海面临多国口音障碍，小商家难以低成本适配全球多元市场。

### ✅ Shopro AIGC 解决方案
*   **AI 数字人克隆**：提供高保真模特库，支持一键表情/语气克隆，零拍摄成本，模特无限出镜。
*   **1分钟极速出片**：基于商品链接一键抓取卖点，自动生产多轨道混剪草稿，后台异步排片。
*   **四步流式脚本**：大模型深入分析用户画像与痛点场景，自动提炼“黄金3秒钩子”，直击消费者心智。
*   **流量预测与优化**：基于竞品爆款模型雷达图进行完播率预测与一键调优，精准掌控 ROI。

## Slide 12: 三、技术解析及亮点 💾 | 后端服务 (API/数据库/并发锁)

### 🔒 Supabase RLS 安全与事务控制
*   **行级安全防护 (Row-Level Security)**：
    *   在 PostgreSQL 层面强制绑定 `(auth.uid() = user_id)` 条件，前端通过 Supabase JS SDK 直接查询，即使客户端代码被逆向，也无法越权访问其他商家的视频资产。
*   **数据库底层积分并发锁 (RPC)**：
    *   积分扣减被统一封装在存储过程 `00013_rate_limit_rpc_and_deduct_credits_v2.sql` 中。
    *   利用 SQL 事务 `SELECT ... FOR UPDATE` 锁住目标用户行，进行余额校验后再执行减免。
    *   **彻底根除并发“薅羊毛”漏洞**：无论前端如何高频并发调用生成接口，数据库事务锁都能保证算力积分扣减百分百准确。

## Slide 13: 三、技术解析及亮点 🤖 | AI能力 (模型/RAG检索/Agent流程)

### 🔄 Deno Agent 流水线编排
1.  **提取阶段**：通过 Deno 函数调用 DeepSeek-V4-Pro 从详情页中清洗爬取的文本，提炼 3 个黄金核心卖点。
2.  **画像分析**：同样由 DeepSeek-V4-Pro 深度分析，推理出目标受众的年龄、身份、痛点与消费场景。
3.  **脚本生成**：Agent 自动将上述卖点和画像编入四层 Prompt 链，流式输出结构化分镜台词。

### 🧠 RAG 检索与 Few-shot 自进化
*   **语义 Embedding**：用户手工修改微调并导出的优秀脚本，会自动调用 Embedding 接口转化为 1536 维向量，存储至 PostgreSQL `pgvector` 中。
*   **Few-shot 模糊检索**：当商家下次创建同品类商品时，Agent 自动利用余弦相似度计算匹配历史高分案例，将其作为上下文 Few-shot 提供给大模型，使 AI 视频风格实现自适应学习与进化。
