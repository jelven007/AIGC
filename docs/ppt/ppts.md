# 演示视觉与素材规范

更新：2026-10-21。配合 [演示提纲](ppt.md) 制作说明材料，替代旧带有宣传评分、虚构能力和个人推广的海报提示词。此文件只定义素材要求，不是已生成图片/幻灯片。

## 视觉与信息

优先使用真实产品截图、架构图、任务状态和可核验样本。每张图注明代码/环境/日期；遮蔽 Key/JWT、账号个人信息和不必要素材。图表必须有数据来源与分母，没有实测值不绘制增长/雷达评分。

架构图显示当前官方 Supabase 与可选火山方案；任务图分别表示创建预占、受理未知核对、完成归档和失败释放。未提交私有媒体/生产任务标“进行中/待验收”，不得把设计图当作真实平台能力。

## 图片与作品

商品图/视频需有来源与使用权，不伪造商家案例、人物同意或测试用户作品。示意图与真实任务输出明确区分。页面截图不显示明文/密文凭据；AI 图片不能用于证明模型设置/任务执行结果。

如另行制作网页图片资源，按实际生成任务与来源约束保存结果，不插入占位图冒充成片。品牌和布局使用清晰可读的文字，不把广告语、价格、二维码交给生图模型做精确排版。

演示与商业材料使用 [当前状态](../CURRENT_STATE.md)、[测试报告](../TEST_REPORT_20261021.md) 的事实；原始视觉草案可查 Git 历史，不能直接复用旧销售承诺。
