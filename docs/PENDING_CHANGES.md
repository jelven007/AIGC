## 需求、方案与开发接受条件

- 素材私有性升级对应 REQ-ASSET-01 与 PRD 私有素材缺口：必须列全对象路径、读取方（浏览器/Worker/供应商）、短效 URL 生命周期、旧对象/旧作品链接迁移、缓存与泄漏边界。
- 同步图片任务化对应 REQ-IMAGE-01 与关页恢复规划：显式 UUID/完整参数绑定、创建时固定模型版本、真实执行器与持久化证据、明确失败补偿、受理未知不重发。
- 渲染/发布/metrics 若要交付，新增专项 PRD 与 API 契约，明确执行器、支持格式/平台、凭据与授权、上游幂等/查询、资源限制、应用价格与客户提示；未接通类型保持不可创建。
- 数据库、Edge、Worker、前端一起更新；禁止仅把公开桶关闭而保留旧 public URL 播放和供应商输入。冻结新任务的发布窗口须考虑浏览器 query 也可执行。
- 新平台 OAuth 配置与模型配置是不同契约：定义管理员来源、平台应用凭据存储/版本、用户连接归属、state 一次性/有效期、回调地址、撤销与令牌刷新。只保存授权状态不证明发布成功；真实发布须有平台作品 ID/终态证据。
- 指标明确曝光/点击/转化字段、数据获取时间、平台支持范围、历史窗口与分母；无数据显示缺失，不回退随机数。完整渲染需定义视频/音频轨道、字幕/字体、导出格式、时长、资源与失败边界，不以预览代替成片。
