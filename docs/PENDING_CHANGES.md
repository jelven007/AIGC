# 待办与接入条件

更新：2026-10-31。本次已授权的目录、文档、合并、发布和本地/线上升级执行状态见[生产基线](releases/PRODUCTION_BASELINE.md)。下面是经营接入与后续能力，不作为当前源码整理未完成项。

| 项目 | 实际条件与核验 |
| --- | --- |
| 正式域名/TLS | 配置ECS域名、有效证书完整链与续期，复核浏览器/宿主/执行器严格TLS |
| 模型供应商 | 配置20槽所需真实权限与价格，验证文本/图片/视频/音频/口型质量和原attempt现金账 |
| 支付 | 提供商户资源，实测签名、到账、查单/关闭/原退款及账单核对；协议测试不代表到账 |
| 身份/法务 | 正式协议地址、短信/邮件服务、限流与送达、历史邀请资格核对 |
| 平台授权 | 抖音/TikTok权限、审核/回调与真实多账号发布，保留逐账号确认 |
| 值班/异地恢复 | 外部告警Relay及回执、异地备份调度/独立密钥保管、定期拉回演练及实测RPO/RTO |
| 原官方业务迁移 | 恢复官方管理权限后只读核对原账、历史素材与密钥，备份并独立迁移验收 |
| 长素材与规模 | 当前100人单机容量已有证据；长素材、真实模型并发及设备质量按具体负载追加测量 |

目录、文档来源和版本身份日常门禁必须保持，历史报告不能替代当前环境健康或商业指标。每次生产变更追加真实验收证据。
