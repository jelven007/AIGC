## 1. 产品定位与范围

服务于有商品素材、需要制作营销脚本和短视频的商家、内容运营与小型团队。核心价值是可追踪、可恢复的生成任务，以及可核对的积分和供应商配置。是否提升转化、节省多少时间必须通过真实业务实验评估。

本期主链路为“登录 → 商品/素材准备 → 脚本与模型选择 → 视频/图片后台任务 → 归档 / 确定失败退积分 → 人工剪辑与FFmpeg成片 → 抖音/TikTok授权发布 → 官方自然视频指标”。批量支持一商品一条视频、整批预算预占、暂停/取消和进度恢复，见 [批量迭代](../ITERATION_09_BATCH_VIDEO.md)。新增 [后台语音与数字人](../ITERATION_11_AUDIO_AVATAR_JOBS.md)：TTS/ASR、即时声纹克隆、照片口播、视频口型同步的真实协议和事务任务已实现并本地验证。云端/供应商仍待验收；自动混剪发布编排、专业声纹/全身训练、全部编辑器效果、其他平台、广告电商归因、自学习和运营后台不在已完成范围。

## 2. 角色与权限

| 角色 | 能力 | 边界 |
| --- | --- | --- |
| 未登录访客 | 查看公开介绍与登录入口 | 不调用模型或读取用户业务数据 |
| 商家用户 | 自己的商品/素材/作品、任务、积分与订单；已启用模型目录 | 不能设置模型密钥、伪造任务状态或操作其他用户积分 |
| 平台模型管理员 | 模型配置、启停、只读连接检查、首次导入 | Auth `app_metadata.role=admin`；服务端与数据库独立校验 |

| MCP 客户端 | 用登录用户 JWT 调用同一业务接口 | 模型/数据库管理员密钥不交给外部智能体 |

运营和财务角色为流程责任，完整后台 RBAC 尚未实现，不宣称已有审批中台。

## 4. 关键流程

视频提交前校验登录、提示词和规格，上传本地参考素材。服务器解析启用配置，并在创建事务内绑定配置版本、预占应用积分。创建响应丢失按原 UUID 找回，不由用户输入生成第二笔消费。

生成中页面可以收起进度或离开；收起不表示取消上游。成功后保存真实成片链接和作品；只有服务端确认失败才释放积分。`UNKNOWN` 或超时的解释应为“受理待核对”，不能提示“已失败/已退款”。用户重新生成确定失败任务是新任务、新 UUID。

模型管理员修改配置先保存版本；新任务使用新版本，旧任务按原版本继续处理。运行端不自动读旧环境密钥。新供应商必须匹配受支持协议，任意 URL 不是自动接入。

| 类别 | 当前规则 | 产品要求 |
| --- | --- | --- |
| 注册 | 免费版初始 20 积分 | 不承诺固定货币兑换关系 |
| 视频 | 配置表默认 10 积分；reserved → settled/refunded | 显示实际配置成本；改价不改变旧任务 |

| 后台语音与数字人 | TTS/ASR默认各2；即时克隆/照片口播/口型默认各10；共用10个未结案媒体任务上限 | 提交前读取并确认价格；换价409零扣费；原受理未知保留积分 |
| 提示词辅助 | 暂不收应用积分；有请求频控 | 仍消耗供应商额度；正式运营前明确预算与收费 |

## 6. 非功能与发布条件

- 正确性优先：资金与任务幂等、终态不可被迟到失败覆盖、配置版本可追溯。
- 身份隔离：关键写 RPC 服务端执行；不能以客户端字段代替服务端授权。
- 凭据：AES-GCM 主密钥只在服务端，浏览器/文档无模型 Key；新私有Storage必须与签名前后端一起部署，旧云端不能据源码宣称已私有。
- 规格限制以适配器为准；参考素材本地上传上限 30MB、成片转存 100MB、图片 20MB、ASR 文件 20MB。
- 当前有频控但无已验证业务 SLA；响应、吞吐、失败率、RPO/RTO 见测试与运行手册的待验收指标。
- 前后端版本一起发布，特别是 00034 与新 RPC 签名。实际环境、模型开通、任务关页恢复与支付验收必须有证据。

## 7. 优先级与不交付事项

P0：补齐当前云端与源码差距、设置管理员/加密主密钥、真实模型权限验收、计费成本和预算。涉及私有内容的用户上线前先完成授权存储。

P1：按模型定价、运行告警与备份恢复演练、MCP新生产工具。图库/团队权限、导出、音频后台化与照片口播已本地交付；Sora按官方退役处理。

P2：批量自动脚本/多镜头/配音/混剪/发布编排、专业声纹/全身数字人训练、完整视频理解/RAG、全部剪辑效果、其他平台/多账号派发、广告电商归因和实验自学习、运营后台。原页面存在或基础API已接入不能作为完整能力交付。
