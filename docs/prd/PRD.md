# 视频生成平台产品需求

核验：2026-10-31。责任：仓库维护者。当前事实来源为48个路由页面、43个生产Edge入口、数据库事务与MCP目录；每次行为变化同步本文。发布与环境验收见[生产基线](../releases/PRODUCTION_BASELINE.md)。

平台服务个人创作者、内容团队和品牌制作人员，主流程为创意/脚本→分镜与素材→视频/配音/剪辑→作品与多规格导出→逐账号确认发布。商品是产品展示类视频的辅助输入。菜单名称统一为「团队协作」「开放平台」「模型接口」。

## 当前范围与接受条件

| 领域 | 当前需求与可核验接受条件 |
| --- | --- |
| 工作台/公开入口 | 展示实际功能和本人近期成片；不填虚构统计，失败保留输入，操作入口可达 |
| 身份/个人中心 | 登录、资料/头像、密码恢复；切换账号清缓存与旧异步结果；本人余额和作品以权威数据为准 |
| 团队/开放平台 | 团队成员/预算/素材共享、受限Key、59工具/19权限；授权范围在服务端核对 |
| 商品/知识/情报 | 私有商品版本与来源、12语言翻译、私有知识检索、授权数据源；来源/预算/留存明确，不能冒充学习或训练结果 |
| 脚本/分镜 | 严格结构、确认正文/配音、原UUID保存恢复；原模型返回异常不替换成模拟成功 |
| 视频/图片 | 持久任务、价格与原配置版本、私有成片/原图；图片扩图/矩形重绘验证原对象与透明掩码，缺能力禁用 |
| 语音/数字人 | TTS/ASR/克隆/照片口播/口型后台任务；用途授权、撤销删除及原任务证据保持 |
| 素材/剪辑 | 私有上传/录音/波形/音轨、时间轴工程、转场/混合/色键/人物蒙版、节拍/字幕；实际播放与长度验证，有界资源与恢复提示 |
| 批次/任务 | 1–50商品、2–6镜头、分阶段预算/依赖/租约；unknown核对原任务，暂停取消与退款按状态执行 |
| 作品/导出/发布 | 本人分页检索/预览/下载、六画幅、抖音/TikTok发布组；实际成片预览后逐账号确认，成功项不重发 |
| 积分/支付 | 权威余额/权益、套餐/流水动作、收银恢复；两渠道签名查单/关单/退款，账务原子幂等，读失败不伪造余额 |
| 运营/客服 | 全部原统计/分页/筛选/详情/工单/风险/租户动作可用；持久授权、过期会话中止写入、原回执核对及按币种现金凭证 |
| 设置 | 模型接口只展示20模型槽和不可变版本；第三方集成单独设置，权限不足只读并说明状态 |
| 通知/观测 | 本人终态通知、未读/偏好/实时隔离；真实来源快照/统计、实验与归因口径明确 |

## 统一产品约束

浅色和深色全站采用鲜明但克制的主题。文字、表单、对话框、表格、提示和手机页需正常可读；横向溢出、遮挡、虚假成功、无反馈按钮及重复提交属于发布阻断问题。

任务在事务中固定原账号、UUID、价格和配置版本。确定失败或未启动取消按原流水退款；已受理未知必须核对，不能因超时重发、盲退或改变旧任务配置。供应商现金与应用积分分别核算。

所有写入经服务端权限/范围检查；账号切换、权限变化和会话过期隔离旧异步结果。私有素材、头像、知识、声纹按引用/用途/撤销规则处理；财务和恢复证据保留，不用删除回执修复状态。
