# 视频生成平台产品需求

类型：reference。读者：产品、开发、测试与运营。责任：仓库维护者。源码核验：2026-11-01。权威来源：apps/web/src/App.tsx、页面与API、43个生产Edge入口、数据库事务和MCP目录。每次行为发布复核；功能或接受条件改变未同步即过期。

平台主流程为创意/脚本→分镜与私有素材→视频/配音/剪辑→作品与多规格导出→逐账号确认发布。商品资料为产品展示视频提供辅助输入。

## 不变量与生产条件

任务事务固定原账号、UUID、价格与模型配置版本。确定失败或未启动取消按原流水退款；受理未知先核对，不重发、盲退或改变旧配置。积分与供应商现金分别核算。模型返回错误不可替换为模拟成功。

切换账号、权限变化、会话过期隔离旧异步结果；私有文件、头像、知识与声纹遵守引用、用途和撤销规则。界面必须清晰可读，遮挡、横向溢出、重复提交和无反馈操作属于阻断缺陷。

当前源码为48页面/13领域、43生产入口、66生产迁移、00068/probe24/render4/edit2、16模型+4集成槽、MCP59/19。升级保持原数据、密钥、卷和容量；两环境分别验收后才能标记发布完成。

真实模型质量/成本、商户到账、SMS/邮件、平台权限、正式域名证书与外部告警/异地备份需经营验收。企业统一账套/自动发票、商业资源交易、自由画笔/多图编辑、专业声纹/全身训练和自动学习投放未交付。
