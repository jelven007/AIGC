## 1. 产品定位与范围

服务于有商品素材、需要制作营销脚本和短视频的商家、内容运营与小型团队。核心价值是可追踪、可恢复的生成任务，以及可核对的积分和供应商配置。是否提升转化、节省多少时间必须通过真实业务实验评估。

本期主链路为“验证身份/权益 → 商品/授权素材与私有知识 → 确认脚本/分镜/价格 → 视频图片及语音数字人后台任务 → FFmpeg剪辑/多镜头配音字幕合成 → 私有作品/多规格导出 → 抖音/TikTok逐账号预览确认发布 → 官方自然指标/签名观测实验”。工单、租户/预算、风险、渠道现金退款、人工供应商账本、告警和隔离恢复为本地交付的支撑链。单视频和2–6镜头批次均支持整批原预算/版本/阶段恢复。

当前未交付完整企业付款账套、商业版权交易、更多原生平台、专业声纹/全身训练、自由画笔/多图编辑界面及自动训练投放。真实模型、SMS、商户、平台、存量迁移和生产容量须目标验收。

## 4. 关键流程

视频提交前校验登录、提示词和规格，上传本地参考素材。服务器解析启用配置，并在创建事务内绑定配置版本、预占应用积分。创建响应丢失按原 UUID 找回，不由用户输入生成第二笔消费。

生成中页面可以收起进度或离开；收起不表示取消上游。成功后保存真实成片链接和作品；只有服务端确认失败才释放积分。`UNKNOWN` 或超时的解释应为“受理待核对”，不能提示“已失败/已退款”。用户重新生成确定失败任务是新任务、新 UUID。

模型管理员修改配置先保存版本；新任务使用新版本，旧任务按原版本继续处理。运行端不自动读旧环境密钥。新供应商必须匹配受支持协议，任意 URL 不是自动接入。

短信使用独立验证会话，回执核对原手机号后才安装全局登录；注册先读取正式条款/隐私和邀请码。奖励仅由数据库实际验证与活动资格发放，读取失败不显示“已到账”。账号切换取消原请求，迟到响应不能改变新账号余额/作品/通知。

图片扩图/重绘先生成并登记同画布原图和透明掩码，确认当前价格/版本；409刷新配置重新确认。多镜头创建固定商品/镜头/台词/音色/各阶段原UUID，配音超时长明确停止合成；真实发布必须预览成片并逐账号确认。

## 6. 非功能与发布条件

- 正确性优先：资金与任务幂等、终态不可被迟到失败覆盖、配置版本可追溯。
- 身份隔离：关键写 RPC 服务端执行；不能以客户端字段代替服务端授权。
- 凭据：AES-GCM 主密钥只在服务端，浏览器/文档无模型 Key；新私有Storage必须与签名前后端一起部署，旧云端不能据源码宣称已私有。
- 规格限制以适配器为准：常规参考素材30MB、视频分析100MB/10分钟、编辑每PNG12MB/原图1600万像素、图片输出20MB、ASR20MB；渲染成片有独立1GB上限，不能套用模型视频转存100MB。
- 当前有频控但无已验证业务 SLA；响应、吞吐、失败率、RPO/RTO 见测试与运行手册的待验收指标。
- 前后端版本一起发布，特别是 00034 与新 RPC 签名。实际环境、模型开通、任务关页恢复与支付验收必须有证据。

## 7. 优先级与不交付事项

P0：补齐当前云端与源码差距、设置管理员/加密主密钥、真实模型权限验收、计费成本和预算。涉及私有内容的用户上线前先完成授权存储。

P1：实际模型成本/质量、目标运行告警和备份调度/异地恢复、商户/平台/SMS/TLS与历史数据验收；MCP59、团队预算/共享、导出、媒体、编排与运营已本地交付。Sora按官方退役处理。

P2：企业统一账套/自动供应商发票、商业资源交易、自由画笔/多图编辑、专业声纹/全身数字人、更多平台、广告原生分流/利润归因/自学习。现有私有RAG和匿名实验保持其有界范围，不能承诺自动训练和无人审核发布。
