# 竞品研究与比较方法

更新：2026-10-21。本文给出可执行研究方法，不沿用无来源价格、功能打勾、雷达评分或“Shopro 胜出”的结论。本轮未重新访问竞品官网/试用账号，因此不提供最新竞品事实。

## 1. 研究范围

候选方向：剪辑/模板工具（如剪映/CapCut）、生成视频工具（如 Runway、可灵）、数字人口播（如 HeyGen）、模型供应商控制台，以及商家原有人工制作流程。名称只表示待研究对象，不代表当前功能或价格。

Shopro 本期是商品脚本/短视频任务与配置/积分可靠性；完整渲染、自动投放、私有素材与运营后台尚未交付。自身基准见 [当前状态](../CURRENT_STATE.md) 与 [PRD](PRD.md)。

## 2. 统一研究表

| 维度 | 必须记录的事实 | Shopro 当前证据 |
| --- | --- | --- |
| 核心工作流 | 输入素材、可控参数、步骤、人工介入 | 视频队列与辅助调用；部分扩展页面模拟 |
| 生成质量 | 商品一致性、字幕/发音、画质、时长、人工接受 | 真实供应商样本尚待验收 |
| 费用 | 日期/地区/币种、套餐、单次、失败/重试/带宽收费 | 视频默认 10 应用积分，供应商账单未测 |
| 恢复与退款 | 页面关闭、超时未知、重试、作品长期存储 | 本地幂等/租约/退款回归；旧云端失败退款实测 |
| 模型/账号 | 支持协议、权限与配置更换影响 | 13 槽、AES-GCM、任务不可变版本；未云端上线 |
| 素材与用户隔离 | 私有访问、导出、保留期限、授权边界 | RLS/ACL；当前 Storage 公开 |
| 自动化接口 | API/MCP、鉴权、计费、幂等 | 7 MCP 工具共用用户 JWT/API；公网未验收 |
| 协作/运营 | 团队、角色、审批、数据来源/投放 | 完整后台/真实发布与数据回流缺失 |

每条外部事实保存官网 URL、获取日期、地区/套餐/版本、实际操作与证据；供应商宣传和亲测分列。无法访问或未测标“未验证”，不能以缺证据标“不支持”。

## 3. 对照实验

使用同一批授权商品素材、同长度/画质/语言要求和同一可接受标准。记录提示词、模型/版本、每次尝试、等待/人工时间、总费用、失败及 unknown、接受原因；全部尝试计入成本。

按商品类别/任务类型分组，人工评审先定义标准后看结果，避免只选择最佳示例。比较“每条接受作品成本、总制作时间、任务恢复、作品可控性”，不能用自行估计的百分制评分代替证据。

## 4. 输出与业务决策

调研成果包括原始事实表、实验样本、限制/异常、优势/劣势与适用场景。价格变化重新核验；未完成样本不画已测雷达图，不宣称更便宜/转化更高。

研究验证 Shopro 的配置/任务可靠性是否能减少客服核对、素材重做和重复消费，并决定优先补同步任务化、私有存储还是渲染/批量。结果回填 [计划书](计划书.md)、[商业化方案](../plan/商业化.md) 与 PRD，未验证的市场规模与销售预测不作为结论。
