# Shopro AI 产品与商业计划

更新：2026-10-21，业务源码 ce90bfe。基于仓库实现与当前运行证据制定计划，替代原来的无来源市场规模、收入预测、融资估值、团队经历和宣传评分。产品现状见 [当前状态](../CURRENT_STATE.md)。

## 1. 执行摘要

产品是商家商品脚本与短视频生产工具。先把“真实模型 → 可恢复视频任务 → 成片归档 → 可核对积分”主链路稳定交付，再验证作品质量、成本和商家持续使用。现阶段完成本地可靠性改造，官方云端仍旧版本，火山是可选迁移工具方案；没有完成商业化验收。

## 2. 用户与问题假设

| 用户 | 待验证问题 | 研究证据 |
| --- | --- | --- |
| 小型商家 | 素材转化成脚本/分镜耗时，模型操作不熟 | 原工作流耗时、任务样本、人工接受原因 |
| 内容运营 | 多商品、多版本管理与生成失败难追踪 | 周期任务量、返工原因、归档检索与重试记录 |
| 小团队 | 账号/费用分散，模型改配置后任务难恢复 | 供应商账单、未知任务比例、处理时间 |

访谈记录实际角色、商品类型、原工具、制作时间、预算、质量要求、付费意愿和素材私有需求。目标用户不通过年龄、行业规模或海外成功故事替代真实需求验证。

## 3. 产品范围与技术依据

React 18/Vite/TypeScript 商家端，Supabase Auth/Data API/Storage/Edge Functions，PostgreSQL 租约队列，13 槽加密不可变配置，视频事务绑定版本，MCP 共用 JWT/API。当前官方托管，火山 BaaS/Pages/ECS/方舟可选；架构见 [技术方案](../TECHNICAL_ARCHITECTURE.md)。

本期交付条件按 [PRD](PRD.md) 与 [测试计划](../TEST_PLAN.md)。批量、完整剪辑渲染、自动发布/数据回流、企业后台和私有素材未完成；前端页面不能当作商业可售清单。同步图片/音频/文本辅助需真实供应商验收，不能沿用过去模拟输出。

## 4. 竞争研究与价值验证

比较完整任务体验、真实质量、每条接受作品成本、恢复/退款、素材访问与供应商管理，而非对页面存在打分。竞品待调研的范围与统一实验方法见 [竞品研究](竞品.md)。

自有差异化候选是配置版本与任务绑定、计费原子性、关页继续与异常核对；已经有本地工程证据，但是否成为客户价值/竞争优势需试点验证。当前不宣称 RAG 自进化、销量提升或独占护城河。

## 5. 收费与财务模型

以套餐/应用积分为当前实现基础；视频默认 10、注册默认 20，均为配置默认值。工作台直接同步调用暂免费但平台付供应商用量。收款/权益具有本地原子与验签验证，商户/现金退款仍有上线边界。

财务测算使用真实输入：活跃客户、付费转化、平均确认收入、每客任务量、接受率、供应商全部失败/成功成本、存储/带宽、支付费、客服时间和固定开支。基准/低/高情景由测量数据填写，收入与现金流分开；没有数据不填三年收入、利润率或估值。

详细定价/预算与阶段条件见 [商业化方案](../plan/商业化.md)。不将未售出的积分、赠分或页面模拟交易记作收入。

## 6. 实施路线与资源

| 阶段 | 必需交付 | 主要责任 | 决策依据 |
| --- | --- | --- | --- |
| 当前环境升级 | 00032–00034、匹配函数、主密钥/管理员、真实模型 | 开发/模型管理员/运维/测试 | 云端必需用例、版本回执 |
| 受控试点 | 授权素材、质量/耗时/成本台账、客服 | 产品/运营/财务 | 同 cohort 激活/接受/成本 |
| 收款准入 | 沙箱/正式回调、权益、账单、客户规则 | 财务/开发/测试 | 交易与权益一致，退款边界明确 |
| 正式运行 | 域名/TLS、预算、监控、备份恢复、容量 | 运维/开发 | 运行演练与实测阈值 |
| 后续扩展 | 同步任务化、按模型定价、批量/渲染/发布 | 产品与研发 | 真实需求优先，专项验收 |

人力按职责分配，不编造 CEO/CTO/算法团队或既往业绩。基础设施选择结合网络可达、平台限制、成本、Auth/Storage 迁移风险；选择火山需独立迁移与验收，不在计划中视为已执行。

## 7. 风险与退出条件

未知受理不能盲目重提；主密钥丢失使历史配置不可解密；公开存储不适合私有素材；同步免费调用可能超过预算；现金退款/后台未完全交付。控制方法以 [运行手册](../RUNBOOK.md) 与 [支付方案](../plan/支付.md) 为准。

出现资金不一致、跨用户访问或供应商用量超出试点预算，暂停受影响新任务并核对旧任务。若质量接受率、成本或留存未达团队确认标准，收窄商品/模型/规格，而不是扩大宣传。
