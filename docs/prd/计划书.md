# 视频生成平台产品与商业计划

更新：2026-10-27，本地迭代01–34及本轮可靠性/容量/恢复优化。产品范围和证据见[实施台账](../archive/reviews/OPTIMIZATION_IMPLEMENTATION_20261027.md)，历史发布基线保留原时点，实际商业效果仍待试点。

知识产品现支持真实私有索引、语义查询和脚本引用，见 [迭代14](../archive/iterations/ITERATION_14_KNOWLEDGE_RETRIEVAL.md)。本地能力不是自动模型训练、持续商业效果或供应商生产验收；试点需00043/17槽与匹配调度，实测召回、事实一致性、费用和延时。默认索引2/查询1积分需用户确认。

本计划基于源码与实际运行证据，不使用无来源规模、预测收入、估值、团队经历或评分；知识摘要中的17槽/00043为历史时点，当前20槽/00068/probe24。运行见[当前状态](../CURRENT_STATE.md)。

## 1. 执行摘要

产品是面向个人创作者、内容团队和品牌制作的视频生成平台。先把“真实模型 → 可恢复视频任务 → 成片归档 → 可核对积分”主链路稳定交付，再验证作品质量、成本和创作者持续使用。商品资料保留为产品展示类创作的辅助输入。下文实施状态保留原记录时点，实际运行见当前状态；商业效果需要试点验证。

## 2. 用户与问题假设

| 用户 | 待验证问题 | 研究证据 |
| --- | --- | --- |
| 个人创作者 | 素材转化成脚本/分镜耗时，模型操作不熟 | 原工作流耗时、任务样本、人工接受原因 |
| 内容团队与品牌制作 | 多作品、多版本管理与生成失败难追踪 | 周期任务量、返工原因、归档检索与重试记录 |
| 小团队 | 账号/费用分散，模型改配置后任务难恢复 | 供应商账单、未知任务比例、处理时间 |

访谈记录实际角色、商品类型、原工具、制作时间、预算、质量要求、付费意愿和素材私有需求。目标用户不通过年龄、行业规模或海外成功故事替代真实需求验证。

## 3. 产品范围与技术依据

React18/Vite/TypeScript商家与运营端，账号布局/查询隔离；Supabase Auth/Storage/43生产Edge入口，PostgreSQL租约与原流水事务，20槽加密不可变版本、MCP59/19共用API、独立FFmpeg和持久告警/加密恢复。官方托管与火山方案独立，架构见 [技术方案](../architecture/TECHNICAL_ARCHITECTURE.md)。

本地范围包括真实商品/私有素材/RAG、图片编辑/视频/媒体、剪辑/多镜头配音字幕成片、多规格/两平台发布组、情报/签名观测实验、工单/租户预算/风险/两渠道退款/人工现金成本、奖励/短信与恢复。目标按PRD/测试计划验收，页面数量不作销售依据。企业统一付款/自动发票、商业资源交易、更多平台、全身训练和自动投放仍待开发。

## 4. 竞争研究与价值验证

比较完整任务体验、真实质量、每条接受作品成本、恢复/退款、素材访问与供应商管理，而非对页面存在打分。竞品待调研的范围与统一实验方法见 [竞品研究](竞品.md)。

自有差异化候选是配置版本与任务绑定、计费原子性、关页继续与异常核对；已经有本地工程证据，但是否成为客户价值/竞争优势需试点验证。当前不宣称 RAG 自进化、销量提升或独占护城河。

## 5. 收费与财务模型

以套餐/应用积分为基础，视频/图片默认10、注册20、新邀请验证双方50；知识/情报/分析/媒体各按实际配置确认价格，多镜头整批预算预占。文本辅助及合成/导出/发布当前0积分仍有上游/基础设施成本。两渠道原路退款与权益回收已本地验证，真实付款/退款到账仍需验收。

财务测算使用真实输入：活跃客户、付费转化、平均确认收入、每客任务量、接受率、供应商全部失败/成功成本、存储/带宽、支付费、客服时间和固定开支。基准/低/高情景由测量数据填写，收入与现金流分开；没有数据不填三年收入、利润率或估值。

详细定价/预算与阶段条件见 [商业化方案](../plan/商业化.md)。不将未售出的积分、赠分或页面模拟交易记作收入。

## 6. 实施路线与资源

| 阶段 | 必需交付 | 主要责任 | 决策依据 |

## 7. 风险与退出条件

unknown不能重提；主密钥丢失影响历史配置；旧目标Storage/存量需私有迁移；免费辅助和基础设施可能超现金预算；真实渠道/身份/外部告警/目标恢复仍待验收。控制按 [运行手册](../operations/RUNBOOK.md)与 [支付方案](../plan/支付.md)。

出现资金不一致、跨用户访问或供应商用量超出试点预算，暂停受影响新任务并核对旧任务。若质量接受率、成本或留存未达团队确认标准，收窄商品/模型/规格，而不是扩大宣传。
